# No QSLリスト

ツール→No QSLリストから起動し、ファイル選択でlogbook内の既存アマチュアログを選びます（複数可）。月はすべて又は1～12、コールサインは大文字小文字を区別しない部分一致です。空欄は全局。条件を変えたら表示を押します。

RMKSの独立した受領印（BURO.R、hQSL.Rなど、.Rで終わる印）が1つでもある交信は除外します。RMKS2以降の文字は受領判定に使用しません。BUROありを除外の初期値はオフです。

〇は単独のBUROあり、ーはBUROなし。先頭列クリックで直接保存し、既存のバックアップ処理を使用します。他のメモ・受領印・RMKS2以降は保持。変更後は一覧を更新し、BUROありを除外がオンなら追加した交信は一覧から消えます。

一覧は古い日時から並び、見出しは固定、ページ分割はありません。元ファイルと行番号はセルのツールチップで確認できます。表示後の外部変更を検知した場合は書込みを停止し、表示し直してから再操作します。
