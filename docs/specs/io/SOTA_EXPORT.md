# SOTA提出用CSV — PSLog 1.00 開発チェックポイント

## 資料と適用範囲

2026-09-11に、利用者が指定したSOTA日本支部の[HOTACA説明](https://www.kawauchi.homeip.mydns.jp/sotajp/hotaca%E7%A9%82%E9%AB%98%E3%82%BD%E3%83%95%E3%83%88%E3%82%A6%E3%82%A7%E3%82%A2%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6/)と、そこからリンクされた[データベース説明・2.2.1 CSVファイルについて](https://www.kawauchi.homeip.mydns.jp/sotajp/sota%E3%83%87%E3%83%BC%E3%82%BF%E3%83%99%E3%83%BC%E3%82%B9%E3%81%AE%E8%AA%AC%E6%98%8E/)を確認した。CSV V2の列順、日付・時刻とBAND/MODEの表記を参考にした。

SOTA本体の現行アップローダーでの実際の受入試験は未実施。説明中には古い画面や例の区切り抜けもあるため、形式を構造として確認し、区切り抜けの例をそのまま複製していない。2026年チャレンジ用グリッド追加、SWL、山頂の実在・有効期間のDB照合は対象外。HOTACAのバイナリやコードを流用していない。

## 操作

入出力 → 特殊なエクスポート → SOTA提出用CSVファイル。

自局コールで候補検索し、出力元自局を選ぶ。その自局に完全一致するログを一覧からチェックする。任意でJST期間（YYYYMMDDhhmm、分まで・両端を含む）とRMKSの部分一致を組み合わせる。RMKSは英字の大小を区別しない。

「対象交信を読み込む」で交信一覧を確定する。条件変更または再読み込みで相手山頂の割当を破棄するため、対象条件を先に決めてから山頂を設定する。出力元・原本行にひも付けて番号を管理し、コールサインだけで複数交信に同じ番号を割り当てない。

- Activator：自局山頂必須。相手山頂は任意。
- Chaser：自局山頂は空欄。全対象交信に相手山頂が必要。
- S2S：自局・相手山頂の両方が必要。同一山頂同士は出力を停止。

相手山頂は別画面で行ごとに編集する。100行ずつページ表示し、「全交信を選択」はページをまたいだ全対象を選ぶ。一括設定はチェック済みで空欄の行だけ。入力済みの番号は保持する。キャンセルは元の割当へ反映しない。「設定を反映」で書式を検査する。山頂番号は全角を半角・英字を大文字に正規化し、英数字の支部コード／英字2文字の地域コード－3桁番号を受け付ける。実在と当日の有効性は判定しない。

## CSV

ヘッダーなし、10列固定、カンマ区切り、CRLF、ASCII（BOMなし）。任意欄も空欄のまま区切りを維持する。

| 列 | 値 |
| --- | --- |
| 1 | V2 |
| 2 | 自局コール（元ログ名から取得、移動サフィックスを保持） |
| 3 | 自局山頂（Chaserは空欄） |
| 4 | UTC日付 DD/MM/YY |
| 5 | UTC時刻 HHMM |
| 6 | SOTA用バンド名 |
| 7 | SOTA用モード名 |
| 8 | 相手コール |
| 9 | 相手山頂、任意の場合は空欄 |
| 10 | 画面で指定した提出用メモ、任意 |

JSTから9時間戻し、UTC日ごとに別ファイルを作る。二桁年の曖昧さを避け、この実装の対象は2000～2099年とする。RSTの専用列はない。RMKSを提出用メモへ勝手に転記しない。メモは半角英数字と記号のみで、カンマはアンダーバー、二重引用符は単一引用符へ変換し、完了表示で通知する。元RMKSは変わらない。

周波数は原本のBAND欄から対応表で変換する。例えば430/433は433MHz、1200は1240MHz、2400は2.3GHz。元ログの実周波数を推測・生成しない。対応表にないBANDは行番号付きエラーで停止する。

AM/SSB/CW/FMは同名。既知のデータ系（FT8/FT4/FT2等）はData、FreeDV等はDV、SSTVはOther。USB/LSBはSSB。FT8 AS等の補足付きFTモードもDataとなる。未知モードを無条件にOtherへ落とさず、出力エラーとして示す。元ログへの未知モード入力制限を追加したわけではない。

## 保存

自動ファイル名には自局、運用種別、自局山頂またはchaser、UTC日付を含める。スラッシュはハイフンに置換。同名ファイルには _001 以降の連番を付け、既存ファイルは上書きしない。

POTAと共通の新規ファイル保存基盤を使う。全交信の変換を終えてから保存し、保存前に原本の外部変更をチェックする。原本変更があれば出力を止めて再読み込みを案内する。複数CSVの途中出力失敗では、作成済みファイルを通知する。一括で原子的に保存するものではない。元TXT・設定・バックアップは変更しない。

山頂割当は今回の画面内だけで保持し、閉じると破棄する。割当専用の保存・再開は未実装。ログの自動提出も行わない。
