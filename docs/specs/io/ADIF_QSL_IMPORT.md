# ADIF QSL取り込み（1.00）

ADI・ADX共通。LoTW/eQSLのサービス別標準項目をPSLogの意味に合わせて変換する。

| 入力状態 | RMKSへの反映 |
| --- | --- |
| LOTW_QSL_SENT=Y かつ LOTW_QSL_RCVD=Y | LoTW.R |
| EQSL_QSL_SENT=Y かつ EQSL_QSL_RCVD=Y | eQSL.R |
| EQSL_QSL_SENT=Y、RCVDが省略/N/R | eQSL |
| LoTW送信済みのみ、受領情報のみ、その他状態 | 自動記号化せず確認事項に表示 |

PSLogの.Rは相互Confirmという決定に従い、両方Yの場合のみ生成する。受領だけYの外部ログは自動確認対象にならないため、必要に応じて内容を確認して編集する。V（検証済み）、I、未知値は今回の自動変換対象外。

既存の独立したLoTW/eQSL記号は対応する.Rへ更新する。同じ記号は重複追加しない。コンテストナンバー、CARD.R、hQSL.R等は保持する。既存の相互確認記号と明示的な未送信・未受領等が矛盾する場合は、既存記号を保持して確認事項に表示する。矛盾を自動解決したものではない。

元の標準項目・日付は、変換に使用したものもADIF_EXTRAへ保持し、取り込みレポートにも元のレコードが残る。原本のADIFファイルは変更しない。取り込み画面の既存の変換確認に統合している。紙カード系の一般QSL項目、hQSL/QRZ等の逆変換は今回の対象外。

出力時の標準項目生成はADIF_QSL_EXPORT.mdを参照。ADIF_EXTRAのJSON全体を標準項目へ戻す処理は未実装で、日付などはCOMMENT内で保持される。

参考仕様: https://adif.org/314/ADIF_314.htm
今回の項目定義は前工程で確認済みのADIF 3.1.4に基づく。
