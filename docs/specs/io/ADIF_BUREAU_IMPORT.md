# 紙カードのADIF取り込み（1.00）

QSL_SENT=YかつQSL_SENT_VIA=Bの場合BUROを反映。
QSL_RCVD=YかつQSL_RCVD_VIA=Bの場合BURO.Rを反映。
元の標準項目はADIF_EXTRAと取り込みレポートに保持する。

発送と受領の両方が明示された場合はBURO BURO.Rを併記する。
既存のQSL一括受領とは異なり、入力に明示された発送情報を再出力時にも失わないため。
同じ記号は追加しない。元のメモ・他サービス記号は保持する。
受領だけあり発送済みか確認できない場合、取り込みの確認事項で返送要否を案内する。
これはQSL一括受領画面のカード記入用結果CSVを生成する処理ではない。

D（direct）だけではPSLogのOQRS依頼・ワンウェイ・補助CARD.Rを区別できない。
そのためD/E/M/経路不明、Y以外の状態は推測でPSLog記号へ変換せず、確認事項と元情報を残す。
既存BUROの発送済み・BURO.Rの受領済みと明示状態が矛盾した場合も、原文保持して確認を促す。
不明項目の保持を含む今回の方式を1.00の紙カードADIF取り込み対応範囲とする。
標準フィールドの全状態をPSLog記号へ一対一に変換するものではない。

Linux Qt offscreen全204テスト成功。ADI/ADX再取り込み、発送受領の保持、返送確認、経路不明、矛盾を確認。
Windows実機・外部ソフト実機は未検証。
