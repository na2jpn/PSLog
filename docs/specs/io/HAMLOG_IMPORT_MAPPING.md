# HAMLOG CSV取り込み 1.00 開発版

[公式インポート説明](https://hamlog.xii.jp/html/HID00079.html)の引用符、空項目、レコード番号ありCSVの説明を参照。列順全体・CP932・時刻書式の対応は開発版マッピングであり、HAMLOG実機からの実データ試験は未完了。

## 読み込みの指定

15列、または先頭にレコード番号のある16列を受け付ける。途中の列数変更は停止。ヘッダー付きCSVは現段階では未対応。先頭レコード番号は備考へ保持し、PSログの既存行番号として上書きには使わない。

文字コードは画面でCP932／UTF-8を選択。UTF-8 BOM付きはBOMを認識。文字化けの自動修復や置換はしない。

日付はYY/MM/DD・YYYY/MM/DD（ハイフンも可）。2桁年は画面の2000年代／1900年代を採用し、各交信の解釈を表示する。時刻はhh:mmJ（JST）・hh:mmU（UTC）。秒ありも読み、非ゼロ秒は備考に元の表記を保持。末尾がない場合は初期状態で要確認、画面からJST／UTCを指定可能。J/Uがある交信はその表記を優先。

## 列対応

| CSV列 | PSログへの変換 |
| --- | --- |
| 1 Call | 相手コール、全角英数を半角化・大文字化 |
| 2 Date、3 Time | JSTへ変換したDATE・TIME。DATEの年で振り分け |
| 4 His、5 My | 送信RST・受信RST。既知デジタルのゼロは+00 |
| 6 Freq | MHzから帯域を判定。元値はRMKSのHAMLOG_EXTRAへ保存 |
| 7 Mode | MODE。未知モードも受け付ける |
| 8 Code | 国内運用と判定できる局の4～6桁数字をJCCJCG候補として保持。所在地DB検証は未実施。その他はHAMLOG_EXTRAへ |
| 9 GL | HIS QTHへ追加。形式不正は要確認 |
| 10 QSL、15 Flags | HAMLOG_EXTRAへそのまま保持。.Rへ意味変換しない |
| 11 Name | RMKSへOP:名前 |
| 12 QTH | ASCIIはHIS QTH。日本語等はRMKSへQTH:原文 |
| 13 Remarks1、14 Remarks2 | RMKSへ順に追加 |

日本語QTHの国内局はHIS QTHをJapanとし、GLがあれば併記。判定は国内コールの限定パターンを使い、JH1HST/KH6のような海外運用サフィックスはJapanと決めつけない。所在地DBの確認済みローマ字は、日本語所在地の完全一致かつCodeが整合するときだけ反映する（現在3件）。元日本語はRMKSへ残す。国外の国名自動判定は未実装。その場合はGLまたは空欄にし、元所在地はRMKSへ保持する。

MY QTH専用列はないため空欄。現在のメイン画面MY QTHを過去交信へ流用しない。Remarks2中のMYQTH等も自動解釈はせず、備考として保存する。

区切り縦線は全角に、改行／タブは可視のバックスラッシュ表記に変換する。解析した元列全体は結果JSONに保存する。CSV原本は変更しない。変換確認チェックが必要。

## 検証範囲と次の確認

合成CSVでCP932、UTF-8 BOM、引用符・カンマ・改行、15/16列、日付・時刻・GLの異常、年越しUTC、2桁年、自局指定、重複、保存結果、画面操作を確認。これはHAMLOG実機の往復試験を代替しない。実機由来CSVの列・QSLフラグ・日付解釈を照合する必要がある。エクスポートCSVも引き続き暫定版。
