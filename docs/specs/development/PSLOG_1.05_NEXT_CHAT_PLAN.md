# PSLog 1.05 — 次チャット開発予定

この文書は **Ver1.05正本から始める次チャット用の予定計画** です。
完成済み仕様と混同しないこと。フリラ対応は、このVer1.05基準から以後のパッチで実装する予定です。

## 1. 主要予定: フリラ対応

既存の標準タブ/コンテストタブはアマチュア無線用として維持し、フリラ対応によって既存機能を壊さないことを優先する。

### 初回起動

新規利用者の初回設定画面を、従来の「アマチュア無線コールサインを1つ入力」だけの画面から拡張する予定。

候補:

- アマチュア無線を使用
- フリラを使用
- 両方を使用

既存ユーザーは、現在のアマチュア無線コールサイン設定をそのまま継承する。アップデート時に既存設定を消したり再入力させたりしない。
フリラ情報は後から設定で追加できる設計とする。

### コールサインの種類を分離

アマチュア無線のコールサインとフリラコールは、内部的にも別種類として扱う方向で設計する。

アマチュア無線:

- 従来どおり半角英数字へ正規化。
- 英字は大文字。
- `/1`, `/P` 等の移動表記を従来仕様どおり扱う。

フリラ:

- 日本語部分は **ひらがなを正規形** とする。
- カタカナ入力はひらがなへ変換する方向。
- 英字部分は半角大文字。
- 数字部分は半角数字。
- 漢字は読みが一意とは限らないため、自動的にひらがなへ変換しない。
- アマチュア無線用のコールサイン正規化をそのまま流用しない。

例:

- `サイタマｘｘ１２３` -> `さいたまXX123`
- `さいたまxx１２３` -> `さいたまXX123`

## 2. 既存機能との分離

- 標準/コンテストの既存ログ仕様はアマチュア無線用として維持する。
- フリラ入力、ログファイル、モード/種別などは必要に応じて専用設計へ分離する。
- PSLog TXT 11項目の既存原本互換を、フリラ対応のために不用意に壊さない。
- 既存利用者の `config`, `logbook`, `bak`, `output` を安全に引き継ぐ。

## 3. Ver1.05基準で既に直してあるもの

- 最近閉じたタブを履歴から復活したとき、タブ固有の自局コールサインを保持する。
- 古い/不完全な履歴で自局コールが欠落している場合だけ、設定済み主コールをフォールバックにする。

## 4. 次チャットのパッチ運用

次チャットでも、各パッチは情報集積から開始する。
ユーザーが `1実装`, `2実装` のように **パッチ番号 + 実装** と明示するまでは実装しない。

## 5. 次チャットの最初に貼る文章

以下をそのまま開始文として使用できる。

---

**PSLog Ver1.05 開発を開始します。**
正本は `PSLog_1.05_CANONICAL_SOURCE.zip` です。
`START_HERE.md` と `HANDOFF.md` を最初に確認し、このZIP以外から再構成しないでください。

このチャットではVer1.05系の開発を進めます。
変更内容はパッチ単位で集積し、「1実装」「2実装」など、そのパッチ番号＋実装と言うまでは実装せず、情報集積のみとしてください。

主要予定は **フリラ対応** です。
新規利用者の初回起動画面は、アマチュア無線・フリラ・両方を扱える構成へ拡張する予定です。
既存のアマチュア無線利用者は現在のコールサイン設定をそのまま引き継ぎます。

アマチュア無線コールとフリラコールは別種類として扱います。
アマチュア無線は従来どおり半角英数字・英字大文字・移動表記を扱います。
フリラコールは、日本語部分をひらがな正規形とし、カタカナはひらがなへ、英字は半角大文字、数字は半角数字へ正規化する方向です。漢字から読みを推測して自動変換はしません。

フリラ対応によって既存の標準・コンテスト・PSLog TXT互換を壊さないことを優先してください。
詳細な予定は `docs/specs/development/PSLOG_1.05_NEXT_CHAT_PLAN.md` を参照してください。
