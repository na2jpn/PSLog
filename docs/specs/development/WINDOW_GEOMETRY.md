# ウィンドウの復元 1.00

メイン画面のクライアント領域をconfig/conf.cfgのwindow_geometryへ保存する。x/y/width/height/maximizedを持ち、Qtの論理ピクセルで扱う。最大化・最小化時は通常サイズを保存し、最小化状態では再起動しない。

起動時に現在のモニター作業領域を取得し、タイトル等のフレーム余白を差し引く。保存矩形と最も重なるモニターを選ぶ。重なる画面がなければ主画面へ中央配置。通常時の目安最低サイズは640×420、初期サイズ1240×780だが、作業領域が小さい場合は画面寸法を優先する。具体寸法は実機確認で調整する開発値。

モニター追加／削除、作業領域・DPI変更、メインの表示先画面変更時にも補正を予約する。最大化中の再補正が無限再入しないよう保護する。最小化中は位置を強制せず、通常表示へ戻った際に補正する。

メインの既存スクロールと、カスタムダイアログ全体のスクロールにより、画面より大きい内容の各操作へ到達できる。カスタムダイアログも表示時の作業領域へ補正するが、個別の前回位置・サイズはこの版では保存しない。OS標準のファイル選択画面とメッセージボックスのレイアウトはQt／OSに任せる。

Windows実機の混在DPI、実モニター抜き差し、フレーム余白、タスクバー配置は未検証。今回の検証はLinux offscreenの描画と作業領域を差し替えたテスト。
