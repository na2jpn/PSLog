# コンテストの県コード補助 — PSLog 1.00

段階3「交信ナンバー」の「JCC/JCGから県コードを補助入力」で開きます。
所在地DBに元ログのJCC/JCGが一致した場合だけ、コードの先頭2桁を候補表示します。
JCGの町村サフィックス付き・郡コードの双方に対応し、先頭ゼロを保持します。
不明コード、種別不一致、GLやコールサインからは推定しません。

100件単位で候補を確認して選択し、採点用の地域の空欄だけに反映します。
既存の手入力値、送受信ナンバー、PSLog原本は変更しません。
採点ルールの地域条件（例: 地域 = 01 なら2点）や地域を使うマルチに利用できます。
県内・県外の定義と対象県は大会ルールで指定してください。
DBは交信当時の所在地の保証ではありません。廃止・変更や大会独自区分は手動確認が必要です。
大会用プリフィックスは引き続き手入力です。

検証: Linux Qt offscreen 210テスト成功。Windows実機は未検証。
