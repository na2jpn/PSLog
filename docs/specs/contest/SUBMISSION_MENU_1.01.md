# 提出ログファイル作成メニュー（Ver1.01）

メニューバーの「コンテスト」を「提出ログファイル作成」へ変更。

| 入口 | 操作 |
| --- | --- |
| コンテスト | サブメニュー：コンテスト提出ログ作成…／コンテストルール管理・編集…／Cabrillo出力テンプレート管理・編集… |
| アワード | 未実装のため無効表示。画面仕様は未決定。 |
| QSOパーティ | QSOパーティ提出ログ作成画面を直接開く。 |

QSOパーティは既存の5段階の提出作成画面を共用。タイトル、形式案内、規約注意文、提出名称のラベルを変更する。内部の出力形式・採点処理は共通。個別のパーティ規約データ追加とは別の変更であり、今回規約データは追加していない。
POTA・SOTAは「入出力 → 特殊なエクスポート」に維持。
ソースと既存のコンテスト調査メモは累積ZIPに含める。

検証：変更したPythonファイルの構文確認済み。現在の環境にPySide6がなくGUI起動未確認。Windows実機確認も未実施。
