# 主催名の表示（Ver1.01）
利用者指示：主催名だけを追加。担当者の死去や管理情報の引継ぎ不足でURL・ドメインが失われることがあり、団体名を情報探索の手掛かりとして残す。
ルールの任意フィールドorganizerに主催名を保存。既存ルールは未登録表示で読込互換を維持。ルール編集画面で入力、管理画面で選択時表示と検索、提出作成のルール選択・提出情報画面に表示。主催者URL欄・リンクボタンは追加しない。既存の規約出典URLデータは従来通り保持。主催名を提出ファイルの独自項目に自動挿入しない。
共催は1欄に併記可。ページ掲載者と主催者を混同しない。
構文、従来ルール読込、主催名の保存読込を確認。GUI起動・Windows実機未検証。
