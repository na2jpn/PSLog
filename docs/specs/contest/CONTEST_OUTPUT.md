# コンテスト提出情報・出力とCabrilloテンプレート

PSLog 1.00 開発途中版、2026-09-11。

## 操作

コンテスト提出ログ作成の段階4で採点を確定させ、次へ進むと段階5を表示します。左側が提出情報、右側が出力プレビューと保存先です。入力欄はタブとスクロールで収め、QSO数でウィンドウを縦に伸ばしません。

「RST・周波数・GL・TXを補完」で、提出用の送受RST、実周波数（kHz）、送信機番号0/1、送受GLを入力できます。100件ずつ表示し、反映するまでは作業コピーだけを編集します。元ログは変更しません。交信ナンバーは段階3の確定値を使用します。宣誓は初期未チェックで、対象条件が変わった場合も解除します。

「入力内容を確認」で必須項目・採点・番号・文字コード・列幅を検査します。入力を変えると確認結果を無効にします。プレビューは先頭1500行まで、ファイルには全行を保存します。ファイル名は対象の運用コールを使い、スラッシュをハイフンに変更します。同名があれば_001等の連番を付け、上書きしません。ログ原本、採点ルール、Cabrilloテンプレートに外部変更があれば保存を停止します。

提出者設定はconfig/contest_submit.cfgへ、出力ファイルが正常保存された後だけ記憶します。JARLは氏名・住所・最大電力・署名、Cabrilloは英字氏名と住所各欄です。コンテスト名・部門・任意項目・宣誓日・宣誓チェックは永続継承しません。設定保存だけ失敗した場合は「出力ファイルは保存済み」と区別して表示します。

## JARL R1.0 / R2.1

拡張子txt、CP932・BOMなし・CRLF。SUMMARYSHEETとLOGSHEETを作ります。R1.0にはCATEGORYNAME、バンド別SCOREとTOTAL、旧任意項目（従事者資格、出力種別、設備、クラブ名）を持たせます。R2.1はTOTALSCOREと新しい任意項目（免許年月日、年齢）、クラブ番号を使用します。

JST/UTCを明示選択。UTCではDATE/TIMEから9時間引き、日付・年またぎも変換します。JARLの案内に沿って、国内はJST、ALL ASIAN DXはUTCを選びます。ログ行のRSTとナンバーは別の項目とし、内部空白やタグを注入する文字を拒否します。

FDを選ぶと段階4の第二マルチをFDCOEFFへ記載します。TOTALSCOREは既にその値を掛けた結果であり、出力時には再度掛けません。第二マルチ未使用でFD出力する場合は設定を促します。運用地・電源を必須にしています（同住所・商用電源も明記可能）。マルチオペは運用者一覧を要求します。クラブ番号はハイフンと先頭ゼロを保持します。

一般QSOのログ行に対応する実装です。SWL専用行やJARLの2波系列別ログは本版では生成しません。クラブ番号からDB名称を表示し、名称検索にも対応します。R1では名称の入力補助、R2では確認用表示として使います。番号は01A-1-1等の英字付きにも対応し、先頭ゼロを保持します。未掲載番号は手入力で出力できます。詳細はCLUB_DB.md。部門コードが実在するか、その大会が要求する追加条件を満たすかの年別ルール照合は未実装です。

## Cabrillo 2.0 / 3.0

拡張子log、CRLF。ヘッダーとQSO行をテンプレートで定義し、日時はUTCです。START-OF-LOG、CALLSIGN、CONTEST、CLAIMED-SCORE、CREATED-BY、END-OF-LOGはソフトが作ります。

2.0はCATEGORY・ARRL-SECTION、3.0はCATEGORY-OPERATOR等の個別ヘッダー・LOCATIONを使用します。選択版と矛盾するヘッダーは拒否します。主催者独自の拡張はX-タグで定義できます。NAME/ADDRESS/OPERATORS/SOAPBOX等の行数・幅と、標準の部門候補も検査します。大会固有の部門組み合わせを網羅した判定ではありません。

config/templates/cabrillo/{id}_{year}.txtにUTF-8 JSONで保存します。管理画面は新規・検索・編集・複製・別名保存・JSON直接編集に対応。変更前のファイルは同ディレクトリ内history/へ保存し、外部変更を検知して置換します。通常は名称・参照年・出典URL・CONTEST初期値、ヘッダーの必須/初期値/候補、QSO列の項目/幅/左右寄せ/部分番号/固定文字、MODE対応表を画面で編集します。

QSO列の部分番号0は全文、1以上は空白区切りの部分を指定します。固定文字「-」等も明示的に指定できます。数字や先頭ゼロを勝手に変換せず、幅超過・不足はエラーです。任意コードは実行しません。

標準MODEをテンプレート表で変換し、FT8/FT4/FT2/FreeDVの補足表記は対応する基本MODEを使えます。表にないMODEは停止します。

HFはテンプレートで「実周波数必須」または「バンド識別値を使用可」を選びます。実周波数はkHz整数で補完し、バンドから推測しません。VHF以上は標準のバンド識別値（例：430→432、1200→1.2G）を出力します。バンドや実周波数が大会で認められるかは、参加年の規約で確認してください。

文字コードはASCIIを初期値とし、主催者指定がある場合にUTF-8/CP932を明示選択できます。QSO行は半角ASCIIのみ。英字氏名・住所と日本語の提出者設定は別に保持し、翻訳しません。初期テンプレートは編集開始用の例であり、特定大会の検証済みプリセットではありません。

## zLog令和版CSV

拡張子csv、34列、ヘッダーあり、UTF-8 BOM付き・CRLF。確認した公式ソースはjr8ppg/zLogのコミットa078794a53df62d9fed756ebd4e205be372597ed（2026-09-11に確認）です。

列順はZLOG_CONTEST_CSV.mdを参照してください。3列目TimeZoneのある現行書式です。保存時刻はJSTまたはUTCの選択値に統一します。NrSent/NrRcvdは確定したナンバー、RSTはzLogが読む整数へ変換します。+00はCSV上0となりますが、元PSログには影響しません。PowerはP/L/M/Hを明示指定します。

zLog定義で送信番号末尾に$Pを付ける場合は、専用チェックで末尾のP/L/M/HをPower欄へ分離してください。チェックOFFでは送信番号全文を保持します。番号の英字が電力コードかどうかを勝手に推測しません。

未対応MODE/BANDは停止し、zLog側のCW/7MHzフォールバックを起こす値を渡しません。実周波数はkHzで渡します。メモ引継ぎは任意で、文字列のバックスラッシュ＋nがある場合はzLogが切り詰めるため停止します。CSVの引用符処理で日本語・カンマ・引用符を保持します。

第二マルチ・地域などのzLog専用設定は移し替えを推測せず未設定とし、対象コンテストをzLogで指定して再計算する運用です。34列構造の照合と自動テストは実施済みですが、zLog実機での再読込は未検証です。出力＝各主催者への提出受理保証ではありません。

参照：[zLog公式ソース](https://github.com/jr8ppg/zLog/tree/a078794a53df62d9fed756ebd4e205be372597ed/zlog)、UzLogQSO.pasのSaveToFileAszLogCsv/LoadFromFileAszLogCsv、UzlogConst.pasのMODE/BAND表。
