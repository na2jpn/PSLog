# 登録した抽出ルール（第一マルチ）— PSLog 1.00

ルール編集の「第一・第二マルチ」で第一マルチを「登録した抽出ルール」にし、
「マルチ抽出ルールを編集…」から追加・条件編集・削除・順序変更を行います。
条件は既存のAND/OR条件編集を使用。上から最初に一致する規則を採用します。
一致なし、条件に必要な情報なし、抽出範囲不足は未確定です。
最後に全件条件を置けば、そこを明示的な既定処理にできます。

抽出元: 受信ナンバー、国内地域の作業値、大会プリフィックスの作業値、国・地域名、大陸。
方法: 全体、単一の数字群、位置と文字数（0起点）。
文字数は位置抽出の場合だけ使用します。数字群は複数あると連結せずエラー。
先頭ゼロを保持し、元の受信ナンバー・原本TXTは変更しません。
採点根拠には「マルチ抽出 N」を追加し、採用規則を追えます。
例: H001を数字群で001、08HWを位置0/長さ2で08。大会公式プリセットではありません。

保存は既存のconfig/rules/{id}_{year}.txtのmulti1内です。
kind=registered、rules配列にwhen/source/kind/start/lengthを保存します。
GUIとJSON直接編集は同じ情報を使います。新しい抽出設定を別のマスターへ分散しません。
既存の抽出方法は継続し、rulesなしの旧ルールも読み込めます。
新しいkind/rulesを使うルールは以前のPSLogでは非対応として拒否されます。
保存履歴・外部変更検出は既存のRuleStoreを使用します。

この機能は有効交信の第一マルチの取り出し方です。第二マルチの集計方式や、
0点交信を有効マルチにする新定義を追加するものではありません。
国の代表プリフィックスから大会用プリフィックスを生成する処理も別です。
