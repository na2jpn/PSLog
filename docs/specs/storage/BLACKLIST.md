# ブラックリスト管理 1.00

config/blacklist.jsonにversion=1、entries配列（call・memo・portable）を保存する。QSOの原本とは別。保存直前の外部変更検知と一時ファイル置換を使用する。

登録ごとの完全一致が既定。portable=trueは登録コールそのものと「登録コール/」で始まる運用に一致する。JA1YYYZやKH6/JA1YYYを勝手に同一局とみなさない。海外プリフィックス推定やワイルドカード入力は未実装。

メインで相手コールをセットした際に警告。セット操作なしで記録した場合も確認する。同一入力中に確認済みの同じ警告を繰り返さない。新しいセット、コール変更、登録内容変更なら再確認する。

警告はOKのみ。記録禁止・交信削除・RMKSへの自動追記はしない。照合ファイルが壊れている場合は照合不能を通知し、記録は継続できる。壊れた管理ファイルは自動初期化しない。

管理画面は新規・検索・編集・削除に対応。削除は既定「いいえ」で確認し、ブラックリスト登録のみを削除する。インポート済み交信の一括警告や履歴編集時の再警告は行わない。
