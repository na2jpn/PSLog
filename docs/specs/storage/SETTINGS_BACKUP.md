# 設定・バックアップ・復元 — Ver1.02

## 役割の分離

PSLogには性格の異なる2種類のバックアップがある。

- **自動保護バックアップ (`bak/`)**: 編集・削除・復元前や終了時に作る軽量なログ単位の世代バックアップ。高頻度で動くため軽量性を優先する。保持数は初期30、10/30/60/100から選択する。
- **今すぐバックアップ（全体ZIP）**: 利用者が明示的に実行する完全バックアップ。軽量化を目的に内容を削らず、`config/` と `logbook/` を相対パスのまま保存する。`bak/`、ソース、実行ファイルは含めない。

`bak/` を全体ZIPへ含めないのは速度のためではなく、バックアップの中へ過去バックアップを再帰的に抱え込んで容量が増え続けるのを避けるためである。

## バージョンアップ前

**PSLogのVerを変更する前には「バックアップ → 今すぐバックアップ」で全体ZIPを作成し、別ドライブやUSB等へ保存する。**
自動保護バックアップは日常的なログ復元用であり、バージョン更新前の完全バックアップの代替とはしない。

後方互換性を基本方針とし、**新しいPSLogは、古いPSLogで作成した全体バックアップを可能な限り復元できるようにする。**
逆方向（新しいVerで作ったバックアップを古いPSLogへ復元）は保証しない。バックアップ形式を将来変更する場合は、旧形式の読込・変換経路を維持する。

## 自動保護バックアップ

自動保護バックアップは常時有効。変更した瞬間の世代削除はせず、次の通常世代整理で保持数を適用する。個別ログの「ログバックアップから復元」は、復元元と現在ログを確認してログ全体を置換する。置換前の現在ログも `bak/` へ保存する。

## 今すぐバックアップ（全体ZIP）

処理前に現在設定を保存し、`config/` と `logbook/` のファイルをZIPへ保存する。保存先は利用者が選択する。ZIP内容と原本状態を確認してから出力し、処理途中の外部変更を検出した場合は停止する。PSLogと協調しない外部エディタとの最終確認直後の競合を完全には排除できない。

Ver1.02以降の全体ZIPにはトップレベルの `PSLOG_BACKUP_INFO.json` を追加する。ここには以下を記録する。

- バックアップ形式番号
- 作成元PSLogバージョン
- 作成日時（JST）
- 各ファイルのSHA-256・サイズ
- `logbook` / `user` / `bundled` の区分

`bundled` は作成元PSLogに同梱された標準ルール・標準DB・標準テンプレート等と同一だったファイル、`user` は設定・利用者追加ファイル・標準から変更されたファイルである。この区分により、旧Verの標準定義で新Verの標準定義を巻き戻さず、利用者が変更した内容は復元できる。

USBや別ドライブへの保存を推奨するが、媒体種別を自動保証はしない。通常の「今すぐバックアップ」では `config/`・`logbook/`・`bak/` 自身を保存先にする指定を拒否する。シンボリックリンクは対象を曖昧にしないため拒否する。

## 全体バックアップから復元

Ver1.02で専用復元を実装した。メニューの **「バックアップ → 全体バックアップから復元」** からZIPを選択する。

復元前にZIP全体を検証し、パストラバーサル、重複パス、暗号化ZIP、破損、manifestとのハッシュ不一致、現在のPSLogで読めないログ・利用者ルール・利用者テンプレート等を検出した場合は原本を変更せず停止する。

復元実行直前には現在の `config/` と `logbook/` を `bak/full-restore-safety/` に全体ZIPとして自動保存する。この安全ZIPは通常の全体バックアップには含まれない。

復元時の基本ルールは以下。

1. `logbook/` はバックアップ時点の内容へ戻す。バックアップに存在しない現在ログも、安全ZIP作成後に削除する。
2. `config/conf.cfg` 等の利用者状態、利用者追加ファイル、利用者が変更したルール／テンプレートは復元する。
3. manifestで `bundled` と記録された旧Ver標準ファイルは、新Verの標準ファイルを巻き戻さないため復元しない。
4. Ver1.01以前など **manifestのない旧形式ZIPも受け付ける。** ログ・設定・明確な利用者ファイルは復元する。現在版にも同名の標準ファイルがあり、旧標準なのか利用者編集なのか判定できないものは現行版を上書きせず、`config/restored_legacy/<日時>/` へ保存して比較できるようにする。
5. 復元後は、旧UI状態が復元した設定を再上書きしないようPSLogを終了する。再起動して復元後の設定・ログを読み直す。

## 設定

設定画面は入力補助・バックアップの2タブ。コールサインとMY QTHの別の初期値は持たず、直近入力を引き継ぐ。記録確認は初期ON。OFFでも入力検証とブラックリスト警告は行う。RST補助ON/OFFを切り替えただけでは編集中のRSTを上書きしない。

設定データの未知項目も保持し、表示中の設定が外部変更された場合は保存を拒否する。古いバックアップの設定に新Verの設定項目が存在しない場合は、現行Verの既定値で補完して読み込む。

月次案内は初期ON。JST年月を `config/conf.cfg` の `monthly_notice` へ保存する。起動時、ログがあり未案内の月なら「今すぐ作成／今回は見送る」を表示する。初回の月も対象。同月は再案内しない。ログがない初期起動では案内なしで当月を記録する。

画面位置・サイズ保存の追加改善は別課題。
