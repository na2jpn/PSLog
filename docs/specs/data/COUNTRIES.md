# 国名・地域の参照補助（1.00開発版）

Jim Reisert AD1CのCTY.DAT、VER20260906を2026-09-11に取得。
原本データ、SHA256と版情報、配布条件をconfig/db/cty.dat、cty_meta.json、cty_LICENSE.txtへ同梱。
https://www.country-files.com/cty/cty.dat
https://www.country-files.com/cty-dat-format/
https://www.country-files.com/copyright/

メイン画面で新しい相手コールを確定したとき、所在地補助ONならHIS QTHへ国・地域名候補を入れる。
利用者は実際に聞いた所在地へ変更できる。既存交信の所在地を一括変更しない。
HAMLOG取り込みでは空のQTH、または日本語所在地をRMKSへ保持して空になったQTHに補完。
確認済み所在地や既存のローマ字所在地は優先し、GLを追加する既存処理も維持する。
所在地補助OFFでは国名DBを使用しない。従来の国内局日本語QTH→Japanと原文保持は従来どおり。

形式処理は完全一致例外を優先、通常は最長プリフィックス一致。大陸の上書き情報も保持。
WAE専用地域は国名候補の対象から外す。返すentity_prefixは地域の代表識別子であり、
WPXなど大会のマルチ用プリフィックスとは異なる。CQ/ITUゾーンは今回の返却値に含めない。

一般の移動コールは自動推測しない。登録済み完全一致例外を除き、JD1や/JD1、
海外プリフィックス付き運用、国外コールの数字移動等は候補なし。
/P、/QRP、日本国内形式の数字サフィックスは基本コールを参照。
/MM・/AMは海上・航空移動として国名を補完しない。
曖昧な運用を基本コールの国へ自動的に戻さない。

CTYは時点の参照データであり、過去の個別運用や交信日別の有効性を保証しない。
完全一致例外も履歴の運用地確認を代替しない。国・地域名の英語表記はDBの表記を採用。
DB破損・メタ情報不一致は通知して停止し、別のDBへ黙って切り替えない。
自動更新機能はない。外部へコールサインを照会する通信はアプリから行わない。

開発テスト162件成功（Linux Qt offscreen）。追加4件で参照局、日本の数字移動、
不確定運用、最長一致と完全一致例外、大陸上書き、日本語QTHの保持と国名補完、
ローカルDB破損時のフォールバック抑止を確認した。
Windows実機・EXEは未検証。
