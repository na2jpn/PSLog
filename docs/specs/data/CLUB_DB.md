# 登録クラブDB連携 — PSLog 1.00

2026-09-11にJARL公式一覧を確認し、登録番号とクラブ名887件を収録しました。代表者・連絡者のコール等はこのDBに含めません。

- config/db/club_db.csv：UTF-8 BOM付き、number / nameの2列。
- config/db/club_db_meta.json：取得確認日、参照期間、出典URL、件数、本体および取得元のSHA-256。
- 公式一覧の対象期間：2025-05-01～2027-04-30。毎年の「○年版」を推測せず、期間を画面に表示します。

## 使い方

コンテスト提出情報の「任意・部門別情報」でクラブ番号を入力すると名称を表示します。「登録クラブを検索」では番号・名称のAND検索、100件ごとのページ表示、選択ができます。R1.0はクラブ名欄が空欄または直前の自動入力値なら更新し、手入力の別名は上書きしません。「DBのクラブ名を使用」またはクラブ選択で明示的に採用できます。R2.1は名称を確認用に表示するだけで、提出するのは番号です。

番号は13-1-7、01A-1-1、40A-1-1などの形を受け付けます。全角を半角、英字を大文字、一般的なハイフン類を半角ハイフンへ正規化します。先頭ゼロは削除せず、DBは番号の完全一致で照合します。01A-1-0001を01A-1-1と勝手に同一視しません。

DB未掲載でも、正しい書式の番号は手入力で出力できます。交信時期がDB参照期間外の場合は当時の登録確認を促します。この一覧は登録情報の参考であり、参加した大会のクラブ対抗集計資格を自動判定するものではありません。

DBとmetaのハッシュ・件数が一致しない場合はDBを使わず、その理由を表示します。手入力による出力は継続できます。DB名称を参照した出力では、確認後にDBが変更されていれば保存を停止します。

## 同梱・更新

利用フォルダーのconfig/dbの組を優先し、両方ともなければ同梱マスターを使います。片方だけ存在する場合や壊れている場合に、古い同梱版へ黙って切り替えません。利用中の自動ネット取得機能はありません。Windowsビルド手順にはCSVとmetaの同梱指定を追加しています（ビルド自体は未検証）。

tools/build_club_db.pyは、開発者が取得した公式一覧HTMLから番号・名称のみを抽出するスクリプトです。ページのスクリプトを実行しません。引数は取得HTML、出力ディレクトリ、確認日、参照開始日、参照終了日。例：

```
python tools/build_club_db.py downloaded-list.html config/db 2026-09-11 2025-05-01 2027-04-30
```

これは既存の配布マスターを更新する開発用操作です。利用者設定や元ログを更新するものではありません。
