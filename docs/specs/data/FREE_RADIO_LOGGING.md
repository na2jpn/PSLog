# フリラログ仕様 — PSLog Ver1.14


## 初回起動

- 初回起動は「アマチュア無線のコールサイン」から始まり、ボタンで「フリラのコールサイン」へ切替可能です。
- フリラ開始では、自局コール、種類、機種名（任意）、年（自動）を設定します。
- フリラで開始した場合、初回の空標準タブをフリラタブへ置き換え、アマチュア無線コール未設定のまま利用開始できます。
- フリラ専用利用時はアマチュア設定 `own` にフリラコールを書き込みません。
- フリラタブから標準/EASY/コンテストタブを作る際、フリラコールをアマチュアコールとして引き継ぎません。
- 機種名空欄のフリラセッションも再起動後に復元できます。

## 保存先と原本形式

フリラの正式な原本は `logbook_flr/` のPSLog TXTです。アマチュア無線の `logbook/` とは混在させません。フリラでもPSLog TXTの11固定項目を維持します。

`DATE | TIME | BAND | MODE | HIS CALLSIGN | RSTs | RSTr | HIS QTH | MY QTH | RMKS | JCCJCG`

新規ファイルはUTF-8 BOM + CRLF。日時はJSTです。

## ログブック識別

- 種類: `CB`, `LCR`, `DCR`, `UHFCB`, `特小`, `BLU`, `ETC`
- 機種名: 任意。自由入力。既存ログから種類別サジェスト。
- 年: QSO日付の年。
- 機種名あり: `YYYY_CALL_種類_機種名.txt`
- 機種名なし: `YYYY_CALL_種類.txt`

同一タブ/プロファイルの識別は `自局コール + 種類 + 機種名` です。年違いのファイルは同じプロファイルとして扱い、年を跨いだ検索/呼び出しに利用できます。

## コールサイン文字規則

自局・相手とも平仮名とASCII英数字を許可します。英字は大文字化します。全角/半角カタカナは平仮名へ変換します。漢字等の許可外文字は入力エラーです。

## 種類からのBAND/MODE自動値

| 種類 | BAND | MODE |
|---|---|---|
| CB | `27` | `AM` |
| LCR | `142/146` | `DIGITAL` |
| DCR | `351` | `DIGITAL` |
| UHFCB | `422` | `FM` |
| 特小 | `422` | `FM` |
| BLU | `2400` | `DIGITAL` |
| ETC | `N/A` | `N/A` |

BAND/MODEは11項目互換のため原本へ保存しますが、フリラ画面では種類から自動設定します。RST初期値は59です。

## タブ

- `＋タブ → フリラタブを追加…` で新規ログブック/タブ作成。
- ログブック作成数は無制限。同時表示は最大4フリラタブ。
- タブ名は `[F]CALL 種類`。
- 選択色は水色系。
- 同一 `CALL + 種類 + 機種名` がすでに開いている場合は新規タブを作らず、既存タブへ移動。
- メニュー `フリラ → フリラタブを呼び出す…` から既存プロファイルを呼び出せる。

## LogSearch

フリラタブ右側のLogSearchは現在の種類だけでなく、同じ自局コールの `logbook_flr/` 全種類を横断します。

表示はHIS CALLSIGNを先頭とし、BAND/MODE列の代わりに `種類` を表示します。

メニュー `フリラ → フリラログ検索・編集` でも同様に種類を `すべて` または個別指定できます。対象自局が `選択してください` の状態では検索できません。

## アマチュアとの分離

- アマチュア検索・編集: `logbook/` のみ。
- フリラ検索・編集: `logbook_flr/` のみ。
- フリラタブ表示中にアマ検索を開く、またはアマ系タブ表示中にフリラ検索を開く場合、別系統の自局コールを初期値として引き継ぎません。
- 全体バックアップ/復元では双方を保存・復元します。
