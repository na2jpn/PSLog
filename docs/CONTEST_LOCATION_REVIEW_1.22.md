# 1.22 運用地の入力条件見直し

- 部門別の自由記入運用地は、空欄だけを理由に採点を停止しません。入力済みの場合の提出運用地との照合は維持します。
- 提出画面で移動運用を選択、または実際の自局コールに /数字・/P・/JD1 がある場合、JARL提出の運用地を必須にします。
- フィールドデーはホーム／移動の区分と運用地記載を確認するチェックを提出画面へ追加。ホーム運用の空欄は許容し、A/Bの移動運用では従来どおり具体的な運用地が必要です。Aの設備・電源確認、係数判定は維持。
- 大会固有の常時必須項目（2026年のオール千葉・オール兵庫・KCJ・KCJトップバンド）、運用形態別の電力条件、運用地一致条件は削除しません。
- 部門別運用地が空欄でも、提出画面に入力した運用地を空欄で上書きしません。
