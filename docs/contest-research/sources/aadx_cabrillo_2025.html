Cabrillo Format for the JARL All Asian DX (AADX) Contest

Date: March 25, 2025
Author: JARL Contest Committee

Cabrillo is a universal contest log submission format proposed by N5KO. That is one of the required formats for e-mailed submission for the All Asian DX (AADX) Contest as well as the JARL's original format.

There are two versions of the Cabrillo format available today. Both version 3.0 and 2.0 of the Cabrillo format can be accepted for the AADX contest.

The basic Cabrillo specification is described at http://www.kkn.net/~trey/cabrillo/ but there are some additional data items are defined below for the AADX contest.

If you have any question, please contact JARL Contest Committee.

Summary Sheet Specification

The descriptions highlighted by green are for version 3.0 only, those highlighted by light blue are for version 2.0 only, and those without any marker are common to version 3.0 and 2.0.

  • START-OF-LOG: version-number
    Must be the first line of the log submission. The version-number is 3.0 or 2.0.
  • END-OF-LOG:
    Must be the last line of the log submission.
  • CALLSIGN: callsign
    The Callsign used during the contest
  • CATEGORY-ASSISTED: (not used in AADX)
  • CATEGORY-BAND: text
    ALL, 160M, 80M, 40M, 20M, 15M or 10M.
  • CATEGORY-MODE: text
    CW or SSB (can be omitted as long as the contest-name is identified properly)
  • CATEGORY-OPERATOR:text
    SINGLE-OP, MULTI-OP or CHECKLOG
  • CATEGORY-POWER: text
    HIGH or LOW.
  • CATEGORY-STATION: (not used in AADX)
  • CATEGORY-TIME: text
    24-HOURS (for Single Operator All-Band 24-hour Category)
  • CATEGORY-TRANSMITTER: text
    ONE or UNLIMITED (MULTI-OP must identify)
  • CATEGORY-OVERLAY: text
    SOSV or SOJR (The option for JA stations which category is SINGLE-OP,ALL)
  • CATEGORY: operator-category band-category power-category [time-category] [mode-category]
    For JARL AADX Contest the operator-category must be one of the following:
    SINGLE-OP, MULTI-ONE, MULTI-MULTI or CHECKLOG.
    The band-category must be one of the following:
    ALL, 160M, 80M, 40M, 20M, 15M or 10M.
    The power-category must be HIGH, LOW.
    The mode-category must be CW, SSB. (can be omitted as long as the contest-name is identified properly)
    NOTE: If you are entering a 24 Hours category (Single Operator All Band 24 Hours), you must also provide the time-category information as 24-HOURS. If you are not entering a 24 Hours category, do not include the time-category information.
  • CLAIMED-SCORE: n
    The claimed-score of the log submission, in integer form such as 1217315 or 19113 or 12.
  • CLUB: text
    Number of the JARL registered club with which the score should be aggregated. (Must be written with JARL registration number.)
  • CONTEST: contest-name
    AADX-CW or AADX-SSB.
  • CREATED-BY: text
    Name and version of the logging program used to create the Cabrillo file. (can be omitted)
  • EMAIL: text
    JARL intends to send emails to the address specified in this field.
  • LOCATION: text
    Used to indicate the location where the station was operating from.
  • NAME: text
  • ADDRESS: text
  • ADDRESS: text
  • ADDRESS: text
    Mailing address. Each line should be a maximum of 45 characters long. Up to 6 address lines are permitted.
  • ADDRESS-CITY: text (optional)
  • ADDRESS-STATE-PROVINCE: text (optional)
  • ADDRESS-POSTALCODE: text (optional)
  • ADDRESS-COUNTRY: text (optional)
  • OPERATORS: callsign1 [callsign2 callsign3...]
    A space-delimited list of operator callsign(s). You may also list the callsign of the host station by placing an "@" character in front of the callsign within the operator list, such as
  • OPERATORS: @N6IJ
  • OFFTIME: (not used in AADX)
  • SOAPBOX: text
  • SOAPBOX: text
  • SOAPBOX: text
    ... [as many as needed...]
    Soapbox comments. (optional for all stations)
    Any location information (indicate the DXCC entity if it's not definitely judged it from the callsign)
    Operator's age. (must be for JA's SINGLE-OP JUNIOR and SENIOR)
  • QSO: qso-data
    QSO data as specified by the Cabrillo QSO data format.
  • DEBUG: n
    The DEBUG: tag is intended for software developers. If the JARL email robot receives a log with the DEBUG: tag set, then it will do all its regular processing and generate an auto-reply message, but it will not save the log into data set provided to the log checking team.

    QSO Template

    
      --------info sent------- -------info rcvd--------
QSO: freq  mo date       time call          rst exch   call          rst exch   t
QSO: ***** ** yyyy-mm-dd nnnn ************* nnn ****** ************* nnn ****** n
QSO:  3798 PH 2005-09-03 1324 K8YU          59  36     JA1RL         59  42     0
000000000111111111122222222223333333333444444444455555555556666666666777777777788
123456789012345678901234567890123456789012345678901234567890123456789012345678901
This is the same format as those for many other contests.
    • freq:
      Actual integer frequency in kHz; if freq not known then 28000, 21000, 14000, 7000, 3500, 1800
    • mo:
      CW or PH
    • date:
      UTC date in yyyy-mm-dd form
    • time:
      UTC time in nnnn form
    • call:
      callsign (only A-Z, 0-9 and / permitted)
    • rst:
      RST
    • exch:
      contest exchange
    • t:
      transmitter id 0, 1, 2, 3, 4 or 5 (not required for SINGLE-OP category and omitted)
