2波種目について

マルチオペの「2波種目」は、「小規模なクラブ局でも楽しめる種目を」という要望によってできた種目です。2波種目では次のような楽しみ方ができます。

  • HF機1台と50MHz機1台だけしかなくても、都心部では楽しく参加できる。
  • HF機が2台あれば、1台で3.5、7MHz、もう一台で14-28のアンテナをつなげばOK。
  • オペレーターも交代で2人いれば大丈夫。

このように、リグやアンテナ、オペレーターの数が少なくても、十分に参加できるのが2波種目です。

2波種目のルールは次のとおり

2波は、いかなる場合も同時に送信できるのは2波（異なる2バンド）以下とし、2波それぞれに「10分間ルール」を適用する。「10分間ルール」とは、バンドを変更したときは受信時間を含めて少なくとも10分間そのバンドにとどまらなければならない、というルール。

10分間ルール

2波種目における10分間ルールについて詳しく解説します。

10分間ルールは、2波の制限を守って頂くための大切なルールです。

＜ポイントその1＞トランシーバの使用台数は無制限。ただし、同時に送信できるのは2波以下。

使用できるトランシーバの台数には一切制限がありません。ただし、同時に送信できる電波は最大2波（異なる2バンド）までと定められています。この２波の送信電波を「送信波系列」と呼び、１つ目の送信波系列および２つ目の送信波系列として区別します。
各送信波系列に使用しているトランシーバには、送信波系列ごとに10分間ルールが適用されます。
すなわち、１つ目の送信波系列で「バンドを変更」してから10分間は、１つ目の送信波系列による他のバンドでの送信はできません。同様に２つ目の送信波系列で「バンドを変更」してから10分間は、２つ目の送信波系列による他のバンドでの送信はできません。
なお、受信については、複数バンドの同時受信も含めて一切制限はありません。

＜ポイントその2＞「バンドを変更した」とみなすのは、バンドを切替えて初めてのQSOを行った時。

「バンドを変更した」ことになるのは、「バンドを切替えて最初にQSOを行った」時点です。コンテスト開始後に初めてQSOを行った場合も、バンドを切替えて最初にQSOを行ったとみなされます。例えば、12時15分にバンドスイッチを7MHzから14MHzに切替えたとします。しかしそれから14MHzで交信相手を探しているうちに5分経過してしまい、14MHzでの最初のQSOが12時20分になってしまいました。この場合「バンドを変更した」時間は12時15分ではなく、12時20分ということになります。従ってそれから10分間、すなわち12時30分になるまでは、他のバンドでQSOをしてはいけません（図1）。他のバンドの受信だけならOKです。


図1 「バンドの変更」の定義

この例で、12時15分にバンドスイッチを14MHzに切替えた後、交信する相手が全く見付からずQSOに至らない場合もあるでしょう。この場合は、QSOを行っていないので、「バンドを変更した」ことにはなりません。つまり14MHz以外の別のバンドにすぐに切替え、そこでQSOを行っても何ら問題はありません（図2）。QSOを行って初めて「バンドを変更した」とみなされるからです。


図2 バンドを切替えてもQSOに至らない場合は「バンドを変更した」ことにはならない。

＜ポイントその3＞10分間の経過は、次にバンドを変更した時の初めての交信で確認。

コンテスト審査の段階で、10分間ルールが正しく守られているかを見る場合、「バンドを変更」した時間(ポイントその1で説明した通り、バンドを切替えて最初にQSOを行なった時間)と、その次に「バンドを変更」した時間を見て、10分以上経過しているかで判断します。つまり、あるバンドでの最初のQSOと最後のQSOの差が10分以上経過している必要はありません。

...
7MHz  12:10 JA1ABC
14MHz 12:20 JA1RL ← 14MHzに「バンドを変更した」時間。
14MHz 12:21 JA2RL
21MHz 12:30 JA3ABC
...

上の例では、12:20が14MHzにバンドを変更した時間とみなされます。従って、12:30までは14MHz以外ではQSOしてはいけません。しかし10分経過した事を示すためにわざわざ12:30分以降に14MHzでQSOした実績を作り、それにより14MHzに10分以上いた事を示す必要はありません。この図の例では12:20から12:21までしか14MHzにいたということにはなりません。12:20から12:29まで14MHzにいたと判断され、10分間ルールを守っていることになります。

一方、次の場合は明らかに10分間ルール違反とみなされます。

...
7MHz  12:10 JA1ABC
14MHz 12:20 JA1RL ← 14MHzにバンドを変更した時間。
14MHz 12:21 JA2RL
21MHz 12:29 JA3ABC ← 10分経過する前にバンドを変更したことが明らか
...

＜ポイントその4＞10分間ルールは2波それぞれに適用される。

送信波系列1と送信波系列2は同時に同じ周波数帯を 使用しないことを除いて、10分間ルールを守りながら、任意にバンドの変更ができます。タイムチャートの例を書くと図3の通りです。

ログは送信波系列1と2について別々に作成するか、または当該QSOが送信波系列1か2かを明記しなければなりません。

デュープチェックは送信波系列1と2での両方のQSOを合わせたものについて行ないます。

各送信波系列は必ずしも1台の送信機である必要はありません。 つまり図3に示している通り、物理的な送信機(TX1,TX2,TX3)を送信波系列が渡ることもOKです。この例では、TX2は初めから(a)時点までの間は送信波系列2 として使われていますが、(b)時点から最後までの間は送信波系列1として使われています。


図3 送信波系列の推移

また、1台の送信機のみを用いて交信した場合でも2波種目にエントリーすることもできます。この場合、すべての交信を同じ送信系列による交信としてログに記載してもよいですし、2つの送信波系列に振り分けてログに記載することもできます。ただし、いずれの場合も各交信の送信波系列がわかるように、ログに送信波系列を記載する必要があります。送信波系列が1つしかない場合および送信波系列を2つに振り分けてログに記載した場合のいずれも、送信波系列ごとに10分間ルールが適用されます。

例えば、1台の送信機のみを用いて下記の順番に交信した場合：

...
#1 7MHz  12:10 JA1YRL
#2 14MHz 12:20 JA1RL ← 14MHzにバンドを変更した時間。
#3 14MHz 12:21 JA2RL
#4 21MHz 12:22 JA3YRL ← 10分経過する前にバンドを変更
#5 14MHz 12:23 JA4RL
...

全てを同じ送信波系列による交信としてログに記載すると#4の21MHzの交信は10分間ルール違反となり得点対象外となりますが、次のように#4を送信波系列2による交信としてログに記載すると10分間ルール違反にはならず得点対象になります。

...
#1 7MHz  12:10 JA1YRL  送信波系列1
#2 14MHz 12:20 JA1RL   送信波系列1  ← 14MHzにバンドを変更した時間。
#3 14MHz 12:21 JA2RL   送信波系列1
#4 21MHz 12:22 JA3YRL  送信波系列2  ← 別の送信波系列のため10分ルール違反にならない
#5 14MHz 12:23 JA4RL   送信波系列1
...

＜ポイントその5＞10分間ルールに違反した交信は無かったものとして扱われる。

10分間ルールに違反した交信は、10分間ルール違反をした局の得点計算において、その交信がなかったものとして扱われます。（10分間ルール違反をした交信によるバンド変更も、そのバンド変更はなかったものとして扱われます。）

ただし、10分間ルール違反をした交信は、交信相手局の得点計算には有効です。

例えば送信波系列1において次のように交信した場合、#4の21MHzにおける交信は14MHzにバンド変更した#2の交信から10分間経過していないため無効となり、#4の交信はなかったものとして扱われます。この場合、#2の交信から10分間経過するまでは14MHzに留まり続けなければならず、その間の14MHzにおける#5の交信は有効となります。#2の交信から10分間経過後に14MHz以外のバンドで行った交信（下記例では21MHzにおける#6の交信）から、新たに10分間そのバンド（下記例では21MHz）に留まる必要があります。

すなわち、下記例では21MHzの10分間のカウント開始は、10分間ルールに違反した#4の交信からではなく、10分間ルールに違反していない#6の交信からとなります。

...
#1 7MHz  12:10 JA1ABC
#2 14MHz 12:20 JA1RL ← 14MHzにバンドを変更した時間。
#3 14MHz 12:21 JA2RL
#4 21MHz 12:22 JA3ABC ← 10分ルール違反のため、この交信は無かったものとして扱われる
#5 14MHz 12:29 JA4RL
#6 21MHz 12:33 JA5YRL ← ここで21MHzにバンド変更したと見なされる
...

＜ポイントその6＞送信波系列を区別していないログは減点や種目変更の可能性がある。

送信波系列を区別していないログは、すべての交信を同じ送信波系列で行ったとみなして10分間ルールの判定を行い、10分間ルールに違反する交信は得点・マルチの対象外となります。

また、送信波系列が3つ以上あるログなど送信波系列が2波に区別できないログは、その内容に応じて減点またはマルチオペオールバンド種目に変更される場合があります。
