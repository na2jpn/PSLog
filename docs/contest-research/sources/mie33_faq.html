■FAQ

Q:オール三重３３コンテストの「３３」の意味は何ですか？
A:「三重」　=>　「三が重なる」　=>　「三三」　=>　「３３」
言葉遊びですが、三重県ではいろいろな場面で33が登場します。
地デジになるまでは三重テレビもUHF33chでした。

Q:女性や中学生はJL部門にしかエントリーできないのですか？
A:いいえ、他の部門にもエントリーできます。
JL部門はビギナー部門として設けています。

Q:コンテストナンバーやマルチが「年齢」なのはなぜですか？
A:コンテスト規約は、参加者すべてに公平な参加条件を設定するものと考えます。
三重県は南北に長く、北部ほど人口が多い傾向があります。
そのため多くのコンテストで採用されている市郡マルチでは、
人口も行政区分も多い北部が有利になり、南部が不利になってしまいます。
そのハンディは無線設備の整わないビギナーほど顕著になります。
一方で、南部の珍しい市郡が全国から呼ばれて得点が増えるという現象も予想されます。
しかし、これも公平性という観点で好ましいことではないと考えています。

以前はナンバーが「年齢」、マルチは「プリフィクス」で制定していましたが、
現在は「年齢」に統一しました。

県外局にとっては魅力がないかもしれませんが、三重県の特殊性をご理解下さい。
なお、「年齢」を知られたくない方は00（ゼロゼロ）を使ってください。
自称年齢でもかまいません。

Q:名誉県人局とは何ですか？
A: 当コンテストは、県内局の参加が少なく、
県外局が交信する局をバンド内で探すのが大変という問題が
解決できずに続いてきました。

そこで、前回の当コンテストで入賞した局を名誉県人局として、
県人局部門へ参加できるようにしました。
そうすれば、県外局ｘ県人局の交信が増えてコンテストが活性化すると考えました。
2010年から規約の微調整をしながら試みており県外局に好評です。

Q:マルチオペレータ部門での「年齢」マルチの送り方は？
A: 複数のオペレータで運用する場合は、
各オペレータの「年齢」をコンテストナンバーとして送信してください。
年齢が違えばクラブ局として送信するナンバーは複数になります。

Q:マルチオペレータ部門の「県人局」資格は？
A:マルチオペ部門参加局の代表者が「三重県生まれ又は居住したことがある」条件を満たす場合、
または、対象局が前回の当コンテストで入賞をした場合にも資格を満たします。
ただし、県外で運用する局にかぎります。

Q:マルチバンド部門の運用可能バンドは？
A:3.8/10/18/24MHzバンドを除く、全アマチュアバンドで運用可能です。
もちろん、貴局の無線局免許証に記載されているバンドに限ります。
