# PSLOG101 方針再確認・実装修正版

2026-09-15。No.別の独立選択、人による申告、明記のない条件で出力を止めないという利用者方針を反映。管理87項目の未定義0を維持。全体554試験合格（Qt offscreen）。全実装後のWindows実機・EXEと利用者による実提出は次段階であり、実施済みとは扱わない。

## 今回の変更

- 新潟No.9はローバンド18種目、No.73は7MHz・ハイバンド30種目として独立した選択項目・実行定義に分離。共通規約を理由にNo.を統合しない。No.73内の7MHz・ハイバンドは区分ごとに独立出力。旧niigata_low_band IDはNo.9用として維持。
- 部門・運用条件画面に対象日時を規約値で初期表示。開催区間ごとに年を含め変更できる。変更値を採点・出力にも反映し、元QSO日時は変更しない。画面で設定した日程外は警告のみで採点・出力継続。運用区間が既定の日程外というだけでは停止しない。運用時間の上限など別の明示条件は維持。内部の既存検証APIはcalendar_advisory未指定の場合に従来の厳格検証を利用できるが、通常画面は本人指定・警告方式。
- JA9 VUのSM/MMで10GHzを上限とする独自制限を解消。既知の上位帯域24/47/77/135/248GHzを利用可能。S10Gは10.1/10.4表記を同じ10GHz帯として扱う。S24G等の原典にない単帯部門は作らない。SM2バンド以上、MM2人以上OPという明示条件は維持。
- 大分の地域・県人資格の判定根拠記入を必須にしない。本人が部門を選択。補足入力は可能で、入力した内容は提出意見へ保持。実際の交換番号・部門の対象地域に関する条件は別途維持。
- 岐阜ジュニアは担当交信数と年齢を申告入力し、参考計算を表示。原ログ件数や行別担当との一致、80%の自動資格判定によって出力を止めない。必要な担当者・年齢・局数は提出情報に保持。部門の自動変更なし。ハーフの片側運用条件は以前の利用者決定どおり維持。
- 秋田原典には2種目上限と禁止3条件が明記されているので維持。マルチ2種目の判定集合の根拠を必須記入にする追加制限は削除。実使用帯域を申告した場合の明示的重複は検出し、未記入を禁止根拠としない。
- CQ VHF Digitalは既知モードに加え任意のモード名を処理し、CabrilloではDGへ出力。原ログのモード名は不変。未知モードという理由だけで排除せず、適否は主催者判断。
- No.37 JARL World Wide RTTYにCabrillo3を追加。CONTEST初期値JARL-WW-RTTYは暫定・編集可。指定済み部門ヘッダー、YOUTH、CHECKLOG、送受RST・交換年齢・UTCを処理。周波数は3.5/7/14/21/28というMHz帯域表示。JARL出力も維持。公海MMは得点掲載・表彰対象外に説明を訂正。
- 画面の確定処理で利用するAccepted/RejectedのQt列挙値をSafeDialogで明示し、部門設定確定時のAttributeErrorを修正。
- 再生成スクリプトの大分へ誤って新潟の大会名を入れる古い編集ミスも除去。再生成した大分の提出名を確認。

## 再確認して変更不要だった条件

ギガヘルツに独自の最低帯数・電信電話両方必須は設定されていない。宮崎の通常オールバンド最低2帯・電信電話両方はFAQに明示があり維持、MKJへは追加していない。山形の個人帯域条件と釧路の個人全帯HF/VU条件は原案に原典根拠があり維持、山形YCや釧路の未明示部門へ追加条件を課していない。
