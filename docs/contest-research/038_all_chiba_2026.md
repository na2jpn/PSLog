## 種目・資格
県内C-、県外X-。個人局種目末尾:
CW / 電話 / MIX（通常マルチ）、1.9 / 3.5 / 7CW / 7電話 / 7 / 14 / 21 / 28 / 50 / 144 / 430 / 1200 / 2400UP / ジュニア / ニューカマー / QRP CW / QRP。
社団局はC-社団/X-社団のみ。表の日本語コードを勝手にPH等へ変えない。QRP CWは表の空白を保持。
個人局はSOのみ、個人局MO不可。社団局はSO/MOいずれも可だが社団種目へ。SOだから個人種目に自動変更しない。
通常CW/電話/MIXマルチとジュニアの帯域は1.9〜2400MHz。5.6/10GHz等を通常マルチへ自動加算しない。
2400UPは2400MHz以上のマルチ。実際の2400/5600/10GHz等で別々に得点・マルチを算出して合算、2400UPという仮想1バンドに統合しない。10GHz専用種目は現行表にない。過去からの変更年度は未調査、ユーザーの旧部門の記憶と現行表を区別。
2400MHzは通常マルチの上端かつ2400UPの下端だが、1部門のみ提出。二重エントリー不可。
ジュニア18歳以下、意見欄に年齢。ニューカマー初開局個人、開催日の3年前の同日以降の局免許、意見欄に免許年月日。
ジュニア/QRP/QRP CWは使用帯域数に関わらずマルチ扱い。QRPは5W以下、430MHz以下（QRP CWを含める設計）。
通常マルチ/ジュニアの2400上限注記にはニューカマー/社団を名指ししていない。これらに勝手に同じ上限を足さず、全体対象帯域と個別注記を分けて保持。
社団は運用者全員の姓名と無線従事者資格を意見欄へ。コールだけで済ませない。
