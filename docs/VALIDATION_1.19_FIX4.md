# PSLog 1.19 FIX4 検証

全体を同一プロセスでunittest discover実行し、結果は添付ログ参照。Linux offscreen環境では従来からQt終了時のネイティブ異常が発生する場合があり、テスト判定とプロセス終了コードは区別する。FIX3で停止した条件保存テストを通過。新規6件で音量検証、ミュート・待機再生・停止、保存前試聴と保存、監視画面の設定参照、既存ウィジェットを閉じない回帰、同梱WAVを検証。配布テストも再実行。
音源は標準PCM WAVと提供MP3を変換したPCM WAV。音量はQSoundEffectへ0〜1で渡す。設定は既存conf.cfg、監視画面の音ON/OFFは従来のcluster_monitor.json。
Windows実音声出力・PyInstaller実行は本環境では未検証。実音声の代わりに再生バックエンドをモックして呼出し・音量・待機・停止を検証。ビルド停止原因の診断は提示画像の停止位置とテスト終了処理から判断したもの。

実行結果：1,047件、50.166秒、unittest判定OK。判定表示後にQt終了時SIGSEGV（exit 139）。関連GUI13件は別プロセス終了コード0、通知音・配布関連17件も終了コード0。全体の正常終了を確認したという意味ではありません。
