# PSLog 1.19 FIX2 累積差分

1.19正本へ上書き可能。FIX1適用済みでも同じ手順で使用可能。版番号は1.19を維持。

## 変更

DXCCの索引を通常プリフィックスと完全一致コールの両方から構成。Conway Reef／Rotuma／Austral／Minami Torishima／North Cook Islands等の完全一致専用エンティティを欠落させない。既存HIS QTHを読取専用で分類する。
LoTWとの照合用表示名を交信当時の国名から分離。対象の表記は利用者提示のLoTW表示に基づく。Saint略記、North/South Cookの単複数、Minamitorishima等を別名として認識する。Cook Islandsのみ、未知の記載、曖昧なJD1は推測しない。
C7Aは局公開説明にDXCC未確定とあるため保留。これはARRLによる公式不認定を意味しない。認定が確認されるまで本ソフトでは件数へ算入せず、理由を付して要確認へ表示する。
申請済のキーを変更しない。国名表記変更で保存済みチェックを失わない。履歴DB・TXT・利用者設定への書換えなし。

## 検証

新規6件を含むDXCC・HIS QTH・申請済管理の関連36件がOK。CP932既定を模したPath.open条件でFIX1＋FIX2全13件がOK、エンコーディング未指定のテキストアクセス0件。国名・ADIF・保存・Windowsパッケージの既存関連42件も終了コード0でOK。関連計78件がOK。
実例の3D2CCC、3D2V、TX7W、JG8NQJ/JD1、E51WL、C7Aを応答固定の交信データで確認。Nauru/Naoero合算と新表示名での申請済保持、TXTバイト不変を確認。
Windows GUI・実機でのFIX2確認は未実施。全体1,016件の結果は1.19正本時点であり、この差分について全件再実行したという意味ではない。
