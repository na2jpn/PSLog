# PSLog Ver1.059 PATCH 09

1. コンテストの埋め込みLogSearch右下ステータスを検索範囲に合わせます。限定ONは「選択中のコンテストログ：N交信 ／ 要確認行N件。」、OFFは「自局コール 全ログ：N交信 ／ 要確認行N件。」です。
2. 標準・コンテスト双方の埋め込みLogSearch表の先頭に「相手コール」列を追加します。
3. コンテストルール表示の情報行を左寄せ・可変高さの行レイアウトへ変更し、長文の右寄り・重なりを防ぎます。
4. 選択中タブは下辺だけを描画せず、下のページとつながって見えるようにします。標準の薄緑背景、コンテスト固有色は維持します。
5. コンテスト提出ログ作成の「○件の候補があります。コンテストを選択してください。」を大きめ太字で強調します。
6. 参加部門は専用の選択ダイアログから選べるようにします。既存の正式部門名・コードを正本とし、地域／運用／モード／電力／バンドを可能な範囲で自動分類して絞り込めます。分類不能な部門も削除せず「その他／未分類」または全件表示に必ず残します。
7. 自動分類は選択補助に限定し、登録済み参加部門の件数・正式名・ID・提出コードを変更しません。
8. VERSIONは1.059です。
