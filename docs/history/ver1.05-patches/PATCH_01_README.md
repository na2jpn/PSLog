# PSLog Ver1.051 / PATCH 01

基準: `PSLog_1.05_CANONICAL_SOURCE.zip`

このZIPは変更ファイルだけの差分です。Ver1.05正本ソースのルートへ上書きしてください。
Ver1.04系PATCH/FIXやVer1.05移行差分を再適用しないでください。

## 実装内容

1. アマチュア無線の標準タブ表示
   - `標準` / `標準2` 等の表示を廃止し、`[A]JH1HST` のように自局コールを表示。
   - 付与文字ありは `[A]JH1HST-JP1220` のようにハイフン区切り。
   - 自局コール未設定時は `[A]標準`。
   - `slot` とタブIDは内部管理用として維持。
   - 同一コール・同一付与文字の標準タブを複数開くことは従来どおり許容。

2. 最近閉じたタブ
   - `＋タブ` の履歴見出しを `最近閉じたタブ20件` へ変更。
   - 標準タブ履歴も `[A]...` の同一表示規則を使用。
   - 最大20件、時間制限なし、再起動後保持という内部仕様は変更なし。
   - 復元時は保存済みのタブ固有自局コールを優先する既存仕様を維持。

3. コンテストタブ
   - 名称、色、履歴表示を変更しない。

4. バージョン
   - ランタイムVERSIONとWindows配布ZIP名を `1.051` へ更新。

## 検証

- Python構文チェックを実施。
- `session_state` の標準タブ表示・履歴復元回帰テストを実施。
- Updater/配布ZIPの `1.051 > 1.05` バージョン順序テストを追加。
- PySide6が利用可能なWindows環境では `python -m unittest discover -v` と `build-windows.ps1` で最終確認してください。
