# PSLog Ver1.055 / PATCH 05

Ver1.054へ上書きする差分PATCHです。

## 変更内容

- ヘルプへ「起動コマンドフラグについて」を追加し、`--reset-window` の用途・挙動を説明。
- ログ検索・編集画面の下部操作を「チェック済みを →」でまとめ、順序を `削除 / POTA / SOTA / QSOパーティ / コンテスト提出 / エクスポート` に整理。閉じる直前へ縦区切りを追加。
- ログ検索のチェック済み交信を、そのままコンテスト提出ワークフローへ渡せる経路を追加。
- 11項目PSLog TXTを維持したままRMKS2を追加。RMKS2がある場合だけ `RMKS1 <<RMKS2>> RMKS2` としてRMKS欄内に保存。
- `<<RMKS2>>` は構造用の予約文字列。RMKS1/RMKS2入力欄には直接入力できない。
- 標準交信入力のRMKSラベル横へ「RMKS2を表示」を追加。表示状態は標準タブごとに保持し、チェックを外すまで維持。
- RMKS2のない既存ログは従来どおり一切の引用・変換なしでRMKS1として扱う。
- 交信編集画面もRMKS1/RMKS2を分離して編集し、将来の `<<RMKS3>>` 以降が存在しても削除しない構造にした。
- LogSearch・一覧・文字検索ではRMKS全体を従来どおり表示・検索可能。
- QSL記号、コンテストナンバー候補、QSOパーティー交換情報、アワード等の意味解析はRMKS1を使用し、RMKS2の自由メモを誤判定しないよう整理。
- QSL更新・インポート補助情報の追記はRMKS1へ反映し、既存RMKS2を保持。
- VERSION / Windows配布名を1.055へ更新。

## Windows側確認候補

- 標準タブで「RMKS2を表示」のON/OFFがタブごとに保持されること。
- `RMKS1 <<RMKS2>> RMKS2` が記録・再読込・編集で往復できること。
- RMKS2を消して保存すると従来RMKS1のみの形式へ戻ること。
- ログ検索・編集下部のボタン順と「コンテスト提出へ…」のチェック済みQSO引継ぎ。
- ヘルプ → 起動コマンドフラグについて。
