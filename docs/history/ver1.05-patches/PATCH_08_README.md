# PSLog Ver1.058 PATCH 08

1. 標準・コンテストの相手コールサイン欄はアマチュア無線用として A-Z / 0-9 / / のみを表示入力として許可します。全角英数字は半角化し、英字は大文字化します。
2. コンテストの「バンド別QSO数」を色付きバッジ表示にします。0.475以下=茶、1.8=赤紫、3.5=赤、7=桃、10=黄、14=緑、18=青緑、21=水色、24=青、28=紫、50=桃紫、144=青緑、430=青、1200=藤、2400以上=青紫です。
3. コンテスト入力の表示を「コンテストナンバー（RMKS）」へ変更します。保存仕様は従来どおりRMKSです。
4. タブの選択下線を廃止し、標準タブの選択中だけ薄緑背景で識別します。コンテストタブは既存の6色の選択背景・枠で識別します。
5. VERSIONは1.058です。
