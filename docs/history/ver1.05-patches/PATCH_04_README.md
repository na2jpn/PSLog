# PSLog Ver1.054 / PATCH 04

Ver1.053へ上書きする差分パッチです。

## 1. Windowsウィンドウ状態のリセット起動

- `pslog.exe --reset-window` を追加。
- 保存済みの `window_geometry` をこの起動時だけ無視します。
- 1360×850を基準に、現在利用できる画面領域へ自動フィットします。
- 保存済みの最大化状態も解除して通常ウィンドウで開始します。
- その後通常終了すれば、現在の位置・サイズが通常どおり `conf.cfg` へ保存されます。

## 2. ログ検索・編集：交信編集画面から削除

- 交信編集画面左下へ `この交信を削除` を追加。
- DATE / TIME / 相手コール / BAND / MODE を表示して `はい / いいえ` で確認します。
- 削除対象は検索し直した類似QSOではなく、編集画面が保持している原本行そのものです。
- 削除前バックアップ、外部変更検出、要確認ログの編集禁止は既存Session保護をそのまま使用します。
- 削除成功後はログ検索一覧を再読み込みします。

## 3. ログ検索・編集：検索条件レイアウト整理

1. `対象自局` / `対象ログファイル [参照…]`
2. `相手コール` / `BAND` / `MODE`
3. `RMKS`
4. `HIS QTH` / `JCC/JCG` / 縦区切り / `MY QTH`
5. `開始日時 JST` / `終了日時 JST`

`対象ログファイル` は従来の手入力・部分一致を維持し、`参照…` でlogbook内TXTを選んだ場合はファイル名を自動入力します。
