# PSLog Ver1.056 PATCH 06

Ver1.055（PATCH 05 FIX1適用済み）へ上書きする差分です。

## 変更内容

- 現在のログファイル表示を1行の中央省略表示へ統一。ツールチップでは常に完全なパスを表示。
- 標準／コンテストの「現在のログファイル」横へ `全件表示` を追加。現在タブの自局コールと対象ログをログ検索・編集へ渡して自動検索。自局またはログ未確定時は無効。
- コンテスト提出ログ作成の検索欄へ候補件数／該当なしの状態表示を追加。
- 読み取り専用のルール・条件表示を追加。
  - コンテストルール表示…
  - QSOパーティルール表示…
  - アワード条件表示…
- 提出ログファイル作成メニューを用途別サブメニュー化。
  - コンテスト提出ログ作成…
  - QSOパーティ提出ログ作成…
  - アワード申請用ログ作成…
- コンテストルール表示では、開催情報に加えて呼び出し方法、交信対象、同一局再交信条件、周波数制限、ナンバー、得点・マルチ、提出情報を優先表示。規約データにない情報は推測せず「公式規約を確認」と表示。
- 「PSLogについて」から不要な免責文1行を削除し、表示バージョンを `VERSION` 連動へ変更。
- 新規標準タブの初期値を 430 MHz / FM / RST 59、新規コンテストタブを 7 MHz / SSB / RST 59へ変更。復元タブは保存値を優先。
- 通常エクスポートを3段階へ整理。
  1. 出力対象・基本条件
  2. 出力項目の対応
  3. 確認・出力
- ADIF/HAMLOGの通常項目は既定定義を固定表示し、RMKS1/RMKS2だけ意味のある出力先を選択可能にした。
- GUIに依存しないルール表示データ生成のため、バンド／モード判定の純粋関数を `activity_values.py` へ分離。

## Windows側で確認してほしい点

- 狭いウィンドウで現在ログパスが中央省略され、マウスオーバーで全文が見えること。
- `全件表示` で現在の自局・現在ログだけがログ検索・編集へ渡され、検索済みで開くこと。自局未設定時は押せないこと。
- コンテスト検索で候補件数表示が入力に追従すること。
- コンテスト／QSOパーティ／アワードの表示専用画面が読みやすく開けること。
- 新規標準タブが 430/FM、新規コンテストタブが 7/SSB で始まること。復元済みタブの値が変わらないこと。
- 通常エクスポートが3段階で進み、ADIF/HAMLOGのRMKS1/RMKS2対応を確認してファイル出力できること。
- 「PSLogについて」が Ver1.056 表示になり、削除対象の免責文がないこと。
