## 実装内容

1. アマチュア無線の標準タブ選択表示
   - 選択中の標準タブだけ、下辺に薄い緑色の2 pxラインを表示。
   - 色は既存の緑アクセント系 `#93bca0` を使用。
   - 標準タブ本体の背景・文字などはQt/Windowsの既存表示を維持。
   - 非選択の標準タブには緑ラインを表示しない。

2. コンテストタブ
   - 既存の6色による表示をそのまま維持。
   - 選択中コンテストタブには標準タブ用の緑ラインを重ねない。

3. バージョン
   - ランタイムVERSIONとWindows配布ZIP名を `1.052` へ更新。

## 検証方針

- GPT側では構文チェックと非GUI回帰テストを実施。
- Windows / PySide6 GUIの実表示とEXEビルドはユーザー側で確認。
- Windows確認点: 標準タブ選択時のみ下辺に約2 pxの薄緑線が表示され、コンテストタブの既存色表示が変わっていないこと。
