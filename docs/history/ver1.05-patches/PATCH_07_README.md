# PSLog Ver1.057 PATCH 07

適用基準: Ver1.056 PATCH 06 + FIX1 適用済みツリー。

## 変更内容

1. 埋め込みLogSearchの相手コールサインを、濃い緑文字＋薄い緑背景のラベル風表示で強調。過去交信件数は通常表示のまま。
2. 標準／コンテストの記録時、入力DATE+TIME JSTが現在JSTと3分以上ずれている場合だけ確認を表示。
   - `いいえ`: 保存せず入力へ戻る。
   - `現時刻で記録`: DATE/TIMEを現在JSTへ更新して保存。
   - `はい`: 入力時刻のまま保存。
   - 標準では、この時刻確認を通過した場合は通常の「記録しますか？」確認を重ねて出さない。
   - コンテストでも3分以上のずれ時だけ時刻確認を出す。コンテストナンバー未入力確認は従来どおり別途行う。
3. 選択中コンテストタブの下辺に、そのタブ自身の濃色で2pxラインを追加。標準タブは従来の薄緑2pxを維持。
4. コンテスト／QSOパーティ／アワードの読み取り専用ルール・条件表示は、Enterキーだけでは閉じない。閉じるボタンまたはEscを使用。
5. ルール表示から開発者向けの「構造化～」表現を除去。情報未登録は「登録なし」、規約上明示的に制限なしと判断できる場合は「制限なし」、判断不能は「公式規約を確認」とする。
6. `公式規約URL` は長いURL文字列ではなく `公式規約を開く` ボタンで表示し、既定ブラウザを起動。フルURLはツールチップで確認可能。
7. 標準／コンテストの `全件表示` を補助ボタンとして21px高へ小型化し、青背景＋白文字の統一デザインへ変更。
8. VERSIONを1.057へ更新。

## Windows確認ポイント

- LogSearchのコールサインだけが濃緑＋薄緑背景で目立つこと。
- 3分未満では時刻確認なし、3分以上では3択確認が出ること。3ボタンそれぞれの保存挙動を確認すること。
- 選択中コンテストタブだけ、そのタブ色の下線が見えること。
- コンテストルール表示でEnterを押しても閉じないこと。
- 「構造化～」の内部用語がルール表示に出ないこと。
- `公式規約を開く` から既定ブラウザで開けること。
- `全件表示` が21px高の青い補助ボタンとして標準／コンテスト双方で揃うこと。
