# PSLog Ver1.053 / PATCH 03

基準: Ver1.052（PSLog Ver1.05正本へPATCH 01・02を適用した状態）

このZIPは変更ファイルだけの差分です。Ver1.052ソースのルートへ上書きしてください。

## 実装内容

1. LogSearchの記録直後編集
   - QSO保存後、現在のSession内で再解析されたQSOから埋め込みLogSearch参照を再構築する。
   - 標準・コンテスト双方を対象とする。
   - ダブルクリック時はまずオブジェクト同一性で解決し、参照が古い場合は同一ログ付与文字内の全項目一致を一意に確認できた場合のみ救済する。
   - 完全一致が複数ある場合は誤ったQSOを推測して開かない。

2. コンテスト高速記録
   - 正常入力時は従来どおりQSOごとの「記録しますか？」確認を出さず即記録する。
   - コンテストナンバーが空欄の場合だけ、赤字で「コンテストナンバーが未入力ですが、このまま記録しますか？」と表示する。
   - 選択肢は「はい」「いいえ」。既定は「いいえ」。
   - 「いいえ」では記録せずコンテストナンバー欄へ戻る。「はい」では空欄のまま記録する。
   - 標準タブの confirm_record 設定・挙動は変更しない。

3. 初期ウィンドウサイズ
   - 保存済みウィンドウ位置・サイズがない場合の既定値を 1240×780 から 1360×850 へ変更。
   - 画面が狭い場合は既存の画面内フィット処理で縮小する。
   - 既存ユーザーの保存済みウィンドウサイズはそのまま復元する。

4. バージョン
   - VERSION / Windows配布名を 1.053 へ更新。

## 検証方針

- GPT側: 構文チェック、非GUI回帰、LogSearch参照再構築・安全な一意救済をテスト。
- Windows側: GUI表示、コンテスト空欄警告の赤字・はい/いいえ、記録直後ダブルクリック編集、初回1360×850、EXEビルドを確認。
