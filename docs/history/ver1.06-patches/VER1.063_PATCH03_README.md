# PSLog Ver1.063 PATCH 03

## 適用基準

- Ver1.06正本へ PATCH01 + FIX1 + FIX2 + PATCH02 を適用済みのソースへ上書きする差分です。
- PATCH02は本来Ver1.062でしたが、配布時にVERSION更新が漏れて1.061表示のままでした。PATCH03で現行VERSIONを **Ver1.063** に是正します。
- Ver1.05系や1.051〜1.059のPATCH/FIXを再適用しないでください。

## 実装内容

### 1. ログ一括処理 JCC/JCG — 最終確認

- 3/3画面の `実行内容を確認しました` を右寄せしました。
- 右下の `実行` と同じ視線で確認→実行できる配置です。

### 2. ログ一括処理 JCC/JCG — 無指定時は最新2,000QSO

- 開始・終了が両方空欄の場合、選択ログ全体の最新2,000QSOを母集団にしてからJCC/JCG補完候補を抽出します。
- 開始または終了のどちらか一方でも日時を指定した場合は2,000件制限を適用せず、指定範囲を抽出します。
- 日時欄直下へ `※ 開始・終了とも空欄の場合は、最新2,000QSOを対象とします。日時を指定した場合は指定範囲から抽出します。` の注釈を追加しました。
- JCC/JCG/QTH照合はキャッシュし、大量ログで同じコード・所在地を繰り返し照合する負荷も抑えます。

### 3. コンテスト 得点とマルチ確認 — 新規/既出を表示

- `4 得点とマルチ（確認）` の表へ `マルチ判定` 列を追加しました。
- 同じバンド・同じマルチの1件目は `新規`、2件目以降は `既出` と表示します。
- バンド別マルチなら同じ値でも別バンドは `新規` です。
- 複数のマルチ集合を持つルールでは、各集合の `新規/既出` を表示します。
- 採点ロジックの重複排除自体は従来どおりで、今回は確認UIからその判定を見えるようにしています。

### 4. コンテストルール表示 — 移動運用の日本語整形

- `SO移動の例外以外は場所を変更していない` 等の内部メモ調表現を、表示時だけ人間向けの日本語へ整形します。
- 例: `シングルオペの移動運用として規約で認められる場合を除き、コンテスト中に運用場所を変更していません`
- 元の規約データ、採点条件、確認条件は変更しません。

### 5. VERSION

- `storage.VERSION` を `1.063` へ更新しました。
- Windows配布ZIP名を `PSLog_1.063_Windows_<timestamp>.zip` へ更新しました。
- 現行VERSIONを直接検証する回帰テストも1.063へ更新しました。
