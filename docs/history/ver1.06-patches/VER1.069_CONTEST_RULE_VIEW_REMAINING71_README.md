# Ver1.069 コンテストルール表示 残り71大会パッチ

## 適用元

Ver1.069 PATCH09 + FIX1 + FIX3 を適用した現行ソースに、先行15大会の「コンテストルール表示・先行15大会パッチ」を適用した状態です。この差分ZIPを同じ階層に展開して上書きしてください。旧版からパッチを積み直す用途ではありません。VERSIONは変更しません。

## 変更内容

登録87ルールファイルのうち、先行15大会以外の71大会について、公式規約を中心とする保存資料と照合し、表示専用の `event.rule_view` に次を記録しました。

- 定型CQ呼び出しが規約にある場合は電話・電信および地域区分の差を表示。指定が確認できない場合は指定なしと明記。
- 県内外・管内外・国内外などの交信相手条件を表示。
- 大会全体または電話部門全体などの大区分にかかる送信出力上限を表示。該当する上限が規約にない場合は共通表示の「制限なし」。
- 通常得点、相手局やバンド・モードによる配点差、デジタルモードの参加・除外、特別得点を、確認できる範囲で表示。

この文面は交信中の参照用で、採点エンジン、提出の必須欄や確認チェックに反映しません。例えば規約の細かな得点差を画面に表示しても、既存の提出側の採点設定を変更したという意味ではありません。採点結果と表示された規約の差が残る大会では、公式規約に基づく提出前の確認が必要です。

富山県非常無線通信訓練のURLを `https://www.jarl.com/toyama/25ham/49OSO.pdf` に変更しました。各大会の原文照合先、登録年度、表示内容、留意点は `docs/development/contest_rule_display_audit_87/REVIEWED_REMAINING71.csv` に掲載しています。照合資料の写しは既存の `docs/contest-research/sources/` にあります。再生成時には `devtools/contest_rule_view_verified_remaining71.json` を表示文の確定元として使います。

## 未確定の出典・年度

- 福岡、オール秋田はユーザー提供の主催規約PDFで照合済みですが、公開された公式規約の直URLは未特定です。島根も保存済み主催規約PDFの直URLは未特定です。URLを推測して登録していません。
- 東京コンテストは登録済みの2024年改訂規約PDFを2026年大会の参照資料として使用しました。2027年の改訂準備告知と混同して年度を変更していません。
- CQ WPX SSBの保存済み共通規約では開催日の年表記が登録年度2026と食い違います。得点本文だけ確認し、登録年は変えていません。
- KCWA CWは登録済み2025年大会の規約を使い、2026年大会として書き換えていません。
