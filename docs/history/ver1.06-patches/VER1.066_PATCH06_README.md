# PSLog Ver1.066 PATCH 06

## 適用元
Ver1.065 PATCH05適用済みソースへ、このZIPを相対パスのまま上書きしてください。

## 主な変更
- QSL一括受領の未一致調査に「入力時刻±3分のQSO」を追加。
- 周辺QSOとのコール差を、プリフィックス・エリア数字・サフィックス・移動表記に分けて表示。
- 実行後に人間向けの結果レポートTXTを生成。
- 未処理が残った場合だけ、元受領TXTと同形式で再投入可能な未処理TXTを生成。未処理0件では作成しない。
- 処理完了後に、結果レポート／未処理を上下のスクロール欄で確認できる最終結果画面を追加。
- 最終結果画面に結果レポート、未処理TXT、結果CSV、回復記録の保存先を表示。
- VERSIONを1.066へ更新。

## Windows確認
1. `python -m unittest discover -v` を実行してください。
2. 未一致行で入力時刻±3分のQSOとコール差表示を確認してください。
3. QSL受領を実行し、結果レポートTXTが生成されることを確認してください。
4. 未処理がある場合のみ未処理TXTが生成され、そのTXTを次回そのまま読み込めることを確認してください。
5. 未処理0件の場合は未処理TXTが作られないことを確認してください。
6. 処理完了後の最終結果画面で、上下のスクロール欄と各出力ファイルのフルパスを確認してください。
7. `build-windows.ps1` 実行時はVer1.066の配布ZIPが生成されることを確認してください。

Linux側では非GUIテストを実施し、PySide6 GUI/Windows/EXE実機確認はWindows側でお願いします。
