# PSLog Ver1.068 PATCH 08

## 適用元

Ver1.067 PATCH07 適用済みソースへ、このZIPの内容を相対パスのまま上書きしてください。

## 実装内容

QSL一括受領「処理の詳細」画面の複数候補選択UIだけを修正しました。

- 一意一致は従来どおりチェックボックスでON/OFFします。
- 複数候補は、同じ入力行ごとに排他的なラジオボタンで1件を選択します。
- 複数候補は初期状態では未選択です。
- 1候補を選ぶと同じ入力行の他候補は自動的に外れます。
- 「全て解除」でラジオボタンも未選択へ戻せます。
- ラジオボタンをクリックすると、その候補行を選択して詳細欄も連動します。
- 未一致・既受領スキップは従来どおり選択できません。
- 表の先頭列名を「処理」から「選択」へ変更しました。
- VERSIONを1.068へ更新しました。

## Windows側確認

1. `python -m unittest discover -v`
2. QSL一括受領で「複数候補」のあるTXTを読み込む。
3. 「処理の詳細へ進む」で、複数候補の左端がラジオボタン表示になることを確認。
4. 同じ入力行の候補Aを選んだ後に候補Bを選ぶと、Aが外れてBだけが選択されることを確認。
5. 別の入力行のラジオボタンは独立して選択できることを確認。
6. 「全て解除」でラジオボタンを含む全選択が解除されることを確認。
