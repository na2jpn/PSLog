# PSLog Change Summary — through Ver1.061
## Ver1.061 / PATCH 01 FIX1 — 2026-09-22
- ルール由来表示の判定を修正。ソース実行・テスト環境で、公式と同名のユーザー作成ルールを誤って `（ユーザー変更）` と表示せず `（ユーザー定義）` と判定するようにした。既存GUI回帰テストも新しい由来表示仕様へ更新。

## Ver1.061 / PATCH 01 — 2026-09-22
- 通常エクスポート、POTA、SOTA、コンテスト提出、QSOパーティー／アワードの日時範囲入力を簡略化。開始・終了は片側だけでも有効、空欄は無制限、`YYYYMMDD` 等の先頭部分入力を開始側の期間先頭／終了側の期間末尾へ展開する共通処理へ統一。
- 日時入力欄へ「先頭だけでも可」「空欄は制限なし」のplaceholderと具体例を追加し、「日時範囲を指定」系の不要なチェックを廃止。
- コンテストの「参加部門と運用条件」で、実務上必要な確認事項だけを赤字タイトルの可変グループへ集約。該当項目がなければグループ自体を非表示とし、インターネット／クラスター／ログソフト等の解釈が争点になりやすい制限はPSLogの確認チェック対象から除外。
- 参加部門の「選択…」を現在値の編集として改善。入力済みの局種・実運用電力で候補を事前フィルターし、現在部門が有効な場合はその部門の分類条件と選択位置を引き継ぐ。
- 公式コンテストルール等の同梱資産をUpdater後に安全に同期する仕組みを追加。PSLogが直前に導入した未変更公式ファイルだけを更新し、ユーザー変更・ユーザー定義は保持。コンテスト一覧では `（ユーザー変更）` / `（ユーザー定義）` を表示。
- Ver1.06更新時に旧公式ルールが残る問題への限定移行を追加。旧ルールとの差分が不要なOPPLACEだけである場合に限り現行公式版へ更新し、その他のユーザー変更は保護。公式定義の過去版は更新前に `history/bundled/` へ退避。
- OPPLACE生成元も再監査し、大会全体で常時必須なのはオール千葉・オール兵庫・KCJ・KCJトップバンドの4大会だけとなるよう修正。
- VERSION / Windows配布名を1.061へ更新。
