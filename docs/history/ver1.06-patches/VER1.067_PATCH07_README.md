## 実装内容

1. QSL一括受領の照合詳細をリッチテキスト化しました。
   - 未一致・複数候補等の「入力 / 照合状態 / 理由」は赤字。
   - 同一コールの候補は薄い黄色背景。
   - 入力時刻±3分にあるコール違いQSOは薄いピンク背景。
   - 詳細文字列は従来どおり選択・コピー可能です。
2. QSL処理詳細画面の実行ボタンを、現在の受領方法を含む `チェック済を受領［hQSL.R］にする` 等の動的表示へ変更しました。
3. 処理結果TXTの末尾に `===== QSL対象となったPSLog原本行 =====` を追加し、今回実際に保存された更新後PSLog原本行をまとめて記録します。
4. VERSIONを1.067へ更新しました。
