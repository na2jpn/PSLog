# PSLog Ver1.069 PATCH09 FIX1

## 対象

Ver1.069 PATCH09 適用済みソースへ上書きする差分です。VERSIONは1.069のままです。

## 修正内容

### 愛・地球博記念コンテスト 2026 ルール表示

JARL東海地方本部の保存済み公式規約 `docs/contest-research/sources/ai_chikyuhaku_2026.html` を基準に表示内容を修正しました。

- 呼び出し
  - 電話: `CQ AIコンテスト`（または `CQ 愛コンテスト`）
  - 電信: `CQ AI TEST`
- 参加資格、全国型（管外局同士も有効）、使用周波数帯、送信出力、移動運用条件、D-STAR、モリゾー＆キッコロの同時送信制限、ナンバー交換、重複交信区分を表示専用データとして登録。
- 旧データにあった、2026公式規約で根拠を確認できない一般的な `required_flags`（レピータ・クロスバンド、リモート、セルフスポット等の一括確認）を削除。
- 採点・提出ロジックへ新しい禁止条件は追加していません。

### ルール表示と提出制限を分離

`event.rule_view` を追加しました。ここは表示専用で、採点や提出可否には影響しません。

呼び出し・周波数等を `required_flags` や提出説明文から推測して表示する処理を安全側へ変更しました。特にRTTYルールの「相手呼出」「周波数変更」といった文章を呼び出し方法／周波数制限として誤表示しないようにしています。

「交信上の禁止・制限」行もルール表示へ追加しました。明示データがない大会は推測せず、公式規約確認の案内を出します。

### 開発用監査

`python devtools/audit_rule_view.py`

で表示専用規約データの未登録項目を一覧できます。他大会については公式資料を確認しながら順次整備し、推測で埋めません。

## Windows確認

1. `python -m unittest discover -v`
2. 「コンテストルール表示」で「愛・地球博記念コンテスト (2026)」を開く。
3. 呼び出し方法が電話/CWとも表示されること。
4. 周波数制限・交信対象・移動運用・禁止/制限が公式規約に沿った文章になっていること。
5. コンテスト提出画面で、根拠のない一般確認チェックが増えていないこと。
