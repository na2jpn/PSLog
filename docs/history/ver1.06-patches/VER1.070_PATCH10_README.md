# PSLog Ver1.070 PATCH10

## 適用元

`PSLog_1.069_CONTEST_RULES_HANDOFF_SOURCE.zip` を基準に、この差分ZIPを相対パスのまま上書きしてください。古い正本・過去パッチから再構成しません。適用後のVERSIONは **1.070** です。

## 実装内容

1. **コンテストルール管理・編集の開催月表示**
   - 左側の選択年一覧と、右側の「前年にはあるが今年にはないルール」一覧へ開催開始月を追加します。
   - 表示例: `愛・地球博記念コンテスト（2026/9） [ai_chikyu]`
   - 開催月は `event.windows` の最初の開催日時から求めます。開催日時を持たない旧/手動ルールは従来の年表示のままです。
   - コンテスト選択画面など、管理画面以外の既存ラベルは変更しません。

2. **提出ログのバンド順並べ替えを標準機能化**
   - JARL提出情報に `ログをバンド順に並べる（同一バンド内は時刻順）` を追加します。
   - 全コンテストで提出時に手動ON/OFFできます。
   - `event.submission.order=band_time` は初期値として扱います。愛・地球博記念コンテストは既存定義により初期ONです。
   - チェックをOFFにすれば、愛・地球博でも強制並べ替えせず元の選択順で出力します。
   - ON時は大会ルールのバンド列順を優先し、未登録バンドは周波数順へフォールバックします。元のPSLogログ順は変更しません。

## テスト

Linux側では `python -m unittest discover -v` を実行します。Windowsでは同じ全テスト後、`build-windows.ps1` とGUI実機確認を行ってください。
