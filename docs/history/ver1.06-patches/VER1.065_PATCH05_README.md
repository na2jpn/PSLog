# PSLog Ver1.065 PATCH 05

## 適用元
Ver1.064 PATCH04 FIX1適用済みソースへ、このZIPを相対パスのまま上書きしてください。

## 主な変更
- QSL受領方法を毎回明示選択（初期値 `選択してください`）。
- QSL照合時刻を±5分以内へ変更し、未一致理由・近似候補を表示。
- `処理の詳細へ進む` の2段階方式を追加。複数候補を人間が選択可能。
- 一意一致はチェック済み、未一致・複数候補は赤字・未選択。
- 既受領 `.R` はスキップ、送付済みタグは `.R` へ昇格、重複タグを作らない。
- 一覧を `BURO判定` に変更（BURO=発送済、BURO.R=発送/受領済）。
- VERSIONを1.065へ更新。

## Windows確認
1. `python -m unittest discover -v` を実行してください。
2. QSL受領一括処理で受領方法が `選択してください` から始まることを確認してください。
3. 実際のhQSL受領TXT等で、一意一致・±5分境界・複数候補・既受領スキップ・BURO→BURO.R昇格を確認してください。
4. `build-windows.ps1` 実行時はVer1.065の配布ZIPが生成されることを確認してください。

Linux側では非GUIテストを実施し、PySide6 GUI/Windows/EXE実機確認はWindows側でお願いします。
