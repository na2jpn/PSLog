# PSLog Ver1.069 PATCH 09

## 適用元

Ver1.068 PATCH08 + FIX1 適用済みソースへ、このZIPの内容を相対パスのまま上書きしてください。
VERSIONは 1.069 になります。

## 実装内容

### ファイルメニュー整理

「ファイル」メニューを次の順に整理しました。

1. 本体の場所を開く
2. ログを再読込
3. 区切り線
4. ログファイルの場所を開く
5. 出力ファイルの場所を開く
6. レポートの場所を開く
7. 区切り線
8. PSLog再起動
9. PSLog終了

- 出力ファイルの場所は `output` を開きます。
- レポートの場所は `reports` を開きます。未作成なら従来のフォルダー表示処理で作成してから開きます。
- 「PSLog再起動」は設定・ログの終了時処理を行った後、PSLog自身を再起動します。

### 交信編集のQSL追加ショートカット

交信編集画面のRMKS直下に次のボタンを追加しました。

- `[LoTW.R]`
- `[hQSL.R]`
- `[eQSL.R]`
- `[BURO.R]`
- `[Other.R]`

ボタンを押すとRMKS末尾へ半角スペースを挟んで受領タグを追加します。RMKSが空欄なら先頭スペースは付きません。
既存の送付済みタグ（例 `BURO`）は `BURO.R` へ昇格し、既に `.R` がある場合は重複追加しません。

### 交信編集のRST配置

- `RSTs（送信）` と `RSTr（受信）` を1段に横並び配置へ変更しました。
- QSL追加行を増やしても、従来より縦方向が不必要に長くならない構成です。

## Windows側確認

1. `python -m unittest discover -v`
2. ファイルメニューの順序・2本の区切り線・名称を確認。
3. 「出力ファイルの場所を開く」「レポートの場所を開く」が正しいフォルダーを開くことを確認。
4. 「PSLog再起動」でPSLogが正常終了後に再起動し、二重起動警告にならないことを確認。
5. 交信編集でRSTs/RSTrが1段に並ぶことを確認。
6. RMKS `33` に `[hQSL.R]` を押すと `33 hQSL.R` になることを確認。
7. RMKS `33 BURO` に `[BURO.R]` を押すと `33 BURO.R` となり、もう一度押しても重複しないことを確認。
