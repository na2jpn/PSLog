# Ver1.069 コンテストルール表示の項目整理

適用先: `PSLog_1.069_CONTEST_RULE_VIEW_WORK_PROGRESS.zip` と `PSLog_1.069_CONTEST_RULE_VIEW_TEST_ENCODING_FIX.zip` を適用済みのソース。ZIP内の相対パスで上書きしてください。VERSIONは1.069のままです。

- 交信ルールから独立した「周波数制限」行を削除。上部の「対象バンド」は維持。
- 「交信上の禁止・制限」を「特殊なルール」に変更。規約表示用の禁止・制限と登録済み時間条件をまとめる。
- 開発・提出メモを丸ごと「その他」の特記事項へ表示する処理を削除。「その他」は参照年・ルールIDのみ。
- 公式規約で確認した提出方法の注意を、表示専用 `rule_view.submission_notes` として「提出」に表示できるようにした。ALL JA8の専用Web提出、問合せ先メールでは受付不可、7月8日必着、紙ログの条件を登録。
- 「7月8日必着」等の締切を日付欄にも表示できるよう解析を調整。

今回も提出判定・採点・確認チェックボックスは変更していません。87大会の表示本文整備は引き続き未完了です。
