# PSLog Ver1.061 PATCH 01

## 適用基準

- 唯一の基準: `PSLog_1.06_CANONICAL_SOURCE.zip`
- Ver1.05系や1.051〜1.059のPATCH/FIXを再適用しない。
- このPATCHは、Ver1.06正本へ相対パスを維持して上書きする差分です。

## 実装内容

### 日時範囲入力

- 通常エクスポート、POTA、SOTA、コンテスト提出、QSOパーティー／アワードの日時入力を共通化。
- 開始・終了は片側だけでも有効。空欄はその方向を無制限として扱う。
- `YYYYMMDD` 等の先頭部分入力を許可。開始側は指定期間の先頭、終了側は指定期間の末尾へ展開する。
- 例: 開始 `20260915` → `20260915000000`、終了 `20260917` → `20260917235959`。
- 日時範囲指定のためだけのチェックボックスを廃止し、placeholderと説明文で入力方法を案内する。

### コンテスト確認事項

- 「参加部門と運用条件」の確認チェックを `確認事項（全て確認して要チェック）` のグループへ集約し、タイトルを赤字表示。
- 選択ルール／部門に該当する項目だけを可変表示し、0件ならグループ自体を非表示。
- インターネット、クラスター、セルフスポット、ログソフト／ソフトウェア等、解釈が争点になりやすいネット・ソフトウェア利用制限はPSLogの確認チェック対象から除外。非表示項目は採点・提出の未確認エラーにも使用しない。

### 参加部門選択

- `選択…` は現在値の編集として開く。
- 入力済みの自局局種と実運用最大電力で候補を事前フィルター。
- 現在選択中の部門が引き続き有効なら、その部門の分類条件と選択位置を引き継ぐ。
- 条件変更で現在部門が不適合になった場合は、現条件に適合する候補を表示して選び直せる。

### 公式ルール／Updater管理

- 公式コンテストルール、コンテスト参照DB、Cabrilloテンプレートを「PSLog管理の同梱資産」として起動時に安全同期する。
- PSLogが直前に導入したまま未変更の公式ファイルは新しい同梱版へ更新。
- ユーザーが変更した公式ファイル、ユーザー独自ファイルは上書きしない。
- 更新前の公式版は `history/bundled/` へ退避。
- コンテスト一覧では、同梱公式との差異に応じて `（ユーザー変更）` / `（ユーザー定義）` を表示。未変更公式には接頭辞を付けない。
- Ver1.06以前の管理情報がない初回移行では、ユーザー変更を誤上書きしないことを優先。既知の旧OPPLACE問題だけは、不要な `opplace` を除けば現行公式版と完全一致する場合に限定して自動修復する。

### OPPLACE

- 大会側で固定運用にも常時OPPLACEを要求するのは、現行登録では次の4大会だけ。
