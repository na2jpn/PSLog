PSLog 1.06 Windows配布確認票

[配布構成]
[ ] ルート直下の通常ファイルは pslog.exe のみ。
[ ] exec\PSLogUpdater.exe が存在する。
[ ] meta\BUILD_INFO.json と meta\PSLOG_UPDATE_INFO.json が存在する。
[ ] config / logbook / bak / output の利用者データを配布ZIPに含めていない。

[起動・ウィンドウ]
[ ] PSLog Ver1.06 と表示される。
[ ] 初回既定サイズは1360×850基準で、狭い画面では画面内に収まる。
[ ] `pslog.exe --reset-window` で保存済み位置・サイズ・最大化状態をリセットできる。

[標準・コンテスト]
[ ] 標準タブは [A]CALL 表示、選択中は薄緑背景。
[ ] コンテストタブは固有色を維持し、選択下辺が不自然に残らない。
[ ] 新規標準タブは430/FM/59、新規コンテストタブは7/SSB/59。
[ ] アマチュア相手コール欄は英数字と / のみで、全角→半角、小文字→大文字になる。
[ ] コンテスト欄が「コンテストナンバー（RMKS）」表示。
[ ] バンド別QSO数が色付きラベルで表示される。

[LogSearch / 編集]
[ ] 埋め込みLogSearch表の左端に「相手コール」がある。
[ ] 記録直後のQSOをダブルクリックして編集できる。
[ ] QSO編集画面から、その原本行だけを削除できる。
[ ] 現在のログファイル横の「全件表示」でログ検索・編集が開き、そのログ全件が表示される。
[ ] コンテストLogSearch状態欄が選択ログ限定/全ログに応じて表示を切り替える。

[RMKS2]
[ ] RMKS横の「RMKS2を表示」で2段目が開く。
[ ] RMKS2表示ON/OFFが標準タブごとに保持される。
[ ] RMKS2ありのTXTは `RMKS1 <<RMKS2>> RMKS2`、RMKS2削除後は従来RMKS1のみへ戻る。
[ ] 既存の OP:"..." やJSONを含むRMKSを壊さない。

[記録時刻]
[ ] DATE+TIME JSTが現在時刻との差3分未満なら従来動作。
[ ] 3分以上なら「いいえ / 現時刻で記録 / はい」が出る。
[ ] 標準では時刻確認後に通常記録確認が二重に出ない。
[ ] コンテストは通常即記録、3分以上のときだけ時刻確認が出る。

[ルール・条件表示]
[ ] コンテスト/QSOパーティ/アワードの閲覧画面が開く。
[ ] コンテストルール表示はEnterだけでは閉じない。
[ ] 長文の「提出」「その他」が重なったり右へ押し込まれたりしない。
[ ] 公式規約を開くボタンが既定ブラウザを起動する。
[ ] 「構造化～」等の内部向け表現が利用者画面に出ない。

[コンテスト提出]
[ ] 検索候補件数が大きめ太字で表示される。
[ ] 参加部門選択ダイアログで全登録部門が失われず、未分類/特殊部門も選べる。
[ ] 最終ステージの「入力内容を確認」「ファイルを保存」が下部固定フッターに表示される。
[ ] スクロールしても上記2ボタンを見失わない。
[ ] 固定運用では、規約上常時必須でない大会でOPPLACEを強制しない。
[ ] 移動運用または /1・/P 等の移動表記ではOPPLACEが必須。
[ ] オール千葉・オール兵庫・KCJ・KCJトップバンドは固定運用でもOPPLACE必須を維持。

[通常エクスポート]
[ ] 3段階（対象・条件 → 項目対応 → 確認・出力）で進む。
[ ] ログ検索・編集からチェック済みQSOを渡した場合、そのQSOだけが対象になる。
[ ] RMKS1/RMKS2の出力先マッピングを選べる。

[Updater]
[ ] 通常の PSLog_1.06_Windows_*.zip を新規配布/アップデートの両方に使える。
[ ] 更新前全体バックアップが必須。
[ ] 同Ver同内容は更新不要、同Ver別内容は修復・再インストール、旧Verは拒否。
[ ] 更新後の自己診断、完了画面、約10秒自動起動、更新ロック解除が正常。
