# PSLog Ver1.077 PATCH07

## 基準

Ver1.076 PATCH06 適用済みソースへ上書きする差分です。

## 実装内容

### EASY専用2ページ入力

- EASYタブは専用画面を使用します。標準ログと同じRepository/PSログTXTへ保存します。
- 右側LogSearchは両ページで常時表示し、標準より少し大きい文字で表示します。
- 1/2ページ: Band、Mode、Sub mode、相手コール、送信/受信RST、次へ。
- 2/2ページ: 1ページ目の確認、His QTH、JCC/JCG、JCC/JCGから名称を入れる、My QTH、RMKS（メモ）、日付表示、編集可能なJST時刻、登録。
- 2ページ目には「最初に戻る」を配置します。
- RMKS2と別管理のログファイル付与文字はEASY画面には出しません。
- 保存後は1ページ目へ戻り、Band、Mode/Sub、My QTHだけを保持します。

### EASYの時刻確認

- 2ページ目を最初に開いた時点の日時を交信日時候補として保持します。
- 登録時に現在時刻との差が5分以上なら、`キャンセル` / `現時刻で登録` / `入力された時刻で登録` を選択します。
- 5分未満でも登録確認ダイアログを表示してから保存します。

### EASYタブ表記

- 自局コール未設定: `EASYタブ`
- 設定後: `[E]JH1HST`、`[E]JH1HST/1` 等
- EASYは別管理のログファイル付与文字を持たず、過去のEASYセッションに付与文字が残っていても復元時に無視します。

### PSLogについて

- 「PSLogについて」をPSRTTY側に合わせた見出し付きの説明画面へ変更しました。
- `PS = Pipe Separate（パイプセパレート）` を明記しました。
- PSログTXTがパイプ区切りテキスト形式であること、コンテストによりJARL電子ログ/Cabrillo等を出力できることを説明します。

## VERSION

`1.077`

Windows配布名は `PSLog_1.077_Windows_YYYYMMDD-HHMMSS.zip`。

## Windows確認ポイント

1. `python -m unittest discover -v` が完走すること。
2. EASYタブが標準画面ではなく専用2ページ画面になること。
3. 1/2→2/2→最初に戻るの画面遷移が動くこと。
4. LogSearchが右側に残り、文字が少し大きいこと。
5. JCC/JCGから名称を入れるボタンが動くこと。
6. 5分以上の時刻差で3択ダイアログが出ること。
7. 保存後にBand/Mode/Sub/My QTHが保持され、相手局情報とRMKSが消えること。
8. ヘルプ→PSLogについてが新レイアウトで表示され、Pipe Separate/Cabrillo説明が読めること。
