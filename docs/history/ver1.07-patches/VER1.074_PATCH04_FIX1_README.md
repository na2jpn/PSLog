# PSLog Ver1.074 PATCH04 FIX1

## 対象

`PSLog_1.074_PATCH04.zip` 適用済みの Ver1.074。

VERSION は **1.074 のまま**です。

## 修正内容

JCC/JCG交信チェックで「集計」を押した後、数千QSO程度でも長時間「集計しています…」のままになる問題を修正しました。

原因は2つありました。

1. ログ走査・集計をGUIスレッドで同期実行していたこと。
2. 集計完了後、折りたたまれて見えないJCC/JCG詳細まで全都道府県・全バンド分を一度に `QTreeWidgetItem` として生成していたこと。

FIX1では以下へ変更しています。

- 集計本体をQtワーカースレッドで実行し、集計中もGUIイベントループを止めない。
- 集計中は `集計しています…` と不定進捗のLoadingバーを表示する。
- 集計中は対象コール、サフィックス条件、集計ボタン、閉じるボタンを一時無効化する。
- 集計完了直後は47都道府県の親行だけを生成する。
- 各都道府県のJCC/JCG詳細は、その都道府県を `▶→▼` で初めて開いた時にだけ生成する。
- 一度生成した県の詳細は再利用し、開閉のたびに作り直さない。
- 集計結果・判定ロジック・JCC/JCGマスター・QSL済判定には変更なし。

## 安全性

この画面の集計は従来どおり読み取り専用です。ワーカースレッドはログファイルを読み取るだけで、QSO原本を書き換えません。

集計中にウィンドウを閉じてワーカースレッドだけが残る事故を防ぐため、集計完了までは閉じる操作を抑止します。

## テスト

追加回帰確認:

- FIX1 UIが `QThread` を使ってバックグラウンド集計すること。
- 不定進捗Loadingを備えること。
- 初期描画では都道府県の子行を作らず、展開時だけ詳細を生成すること。
- PATCH04既存のアマチュアログ分離、JCG郡単位集計、QSL状態判定を維持すること。

Windowsでは適用後に次を実施してください。

```powershell
python -m unittest discover -v
```

続いてJCC/JCG交信チェックで実データを集計し、

1. Loading表示中もウィンドウが応答すること
2. 集計完了後すぐ都道府県一覧が表示されること
3. 都道府県を開いた時にJCC/JCG詳細が表示されること

を確認後、通常どおり `build-windows.ps1` でビルドしてください。
