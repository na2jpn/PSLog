## 実装内容

### 1. コンテスト提出のメールアドレスを標準必須化

JARL R1.0 / R2.1の対話型提出画面では、大会個別ルールの `required_fields` にメール指定がなくてもメールアドレスを必須としました。

- 画面表示: `メールアドレス ＊`
- `入力内容を確認` で空欄・空白のみを拒否
- 過去のJARL提出TXTを読み直す低レベル互換性は維持し、対話型の新規提出作成側で必須化

### 2. 愛・地球博記念コンテストのJSTを回帰確認

既存ルールは `event.submission.zone = JST` です。提出画面へ進んだ際に大会ルールのJSTを初期値として設定する既存動作を維持し、回帰テストへ明示しました。

ルール自体の時刻指定は変更していません。

### 3. 「2 対象ログ」の縦空白を再調整

対象自局フォームの垂直SizePolicyを `Fixed` にし、フォームとログ一覧の間にWindows環境で再発していた大きな空白を抑えます。DPI/フォントに応じたsizeHintは使うため、高さをピクセル固定していません。

### 4. 「3 交信ナンバー確認」の ↓↓↓ 周辺を圧縮

`↓↓↓` ラベルを垂直方向 `Fixed` に変更し、余剰高さを受け取らないようにしました。上下paddingも最小化しています。

### 5. 愛・地球博の概要「送信出力」表示を修正

コンテスト概要の送信出力は、表示専用 `event.rule_view.power` が登録されている場合、それを優先するようにしました。

愛・地球博記念コンテストでは次の表示になります。

`電話部門は20W以下（HF帯は10W以下）。`

QRP等の個別種目の上限を大会共通の送信出力制限のように `5 W / 10 W / 20 W` と混在表示しません。採点・提出拒否条件は変更していません。
