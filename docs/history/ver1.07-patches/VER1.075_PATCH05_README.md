# PSLog Ver1.075 PATCH05

## 対象

Ver1.074 PATCH04 + FIX1 + FIX2 適用済み環境。

## 変更内容

### 1. JCC/JCG交信チェックの都道府県行を簡潔化

QSL済は交信済を包含するため、都道府県内の全JCCまたは全JCGがQSL済の場合は、同じ種別の「全...-交信済」を重ねて表示しません。

例：

```text
11.神奈川県　全JCC-QSL済　全JCG-交信済　（CFM 残JCG 2）
```

CFM残数は、その都道府県の現行JCC/JCGマスター単位のうちQSL受領済でない件数です。未交信も未CFMに含みます。残数0の種別、または該当するJCC/JCGがない種別は表示しません。両方0ならCFM括弧自体を表示しません。

### 2. 相手コールサイン入力を太字化

通常ログとコンテストの交信入力で、次を太字にしました。

- 「相手コールサイン」ラベル
- 相手コールサイン入力欄の入力文字

入力・検索・記録ロジックは変更していません。
