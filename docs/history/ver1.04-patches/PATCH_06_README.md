# PSLog Ver1.04 PATCH 06 — Ver1.045

PATCH 05 + FIX1 適用済みの Ver1.044 ソースへ上書きする差分です。

## 変更内容

### 標準タブ「交信入力」の上部余白

- `QGroupBox` 全体のmarginは変更しません。
- 「相手コールサイン」ラベルを縦方向に膨張させず、標準タブ上部だけが間延びしないようにしました。
- 余った高さは「所在地補助」行と「バンドを維持」行の間へ逃がします。
- Date/Time以降の既存レイアウトは維持します。

### DATE/TIMEの柔軟入力

保存時は従来どおり `YYYY-MM-DD` / `HH:MM` へ統一しますが、手入力では次の表記を受け付けます。

DATE例:
- `20260909`
- `2026/09/09`
- `2026/9/9`
- `2026-9-9`
- `2026年9月9日`
- 全角数字・全角記号

TIME例:
- `1515` → `15:15`
- `915` → `09:15`
- `15:15`
- `1:1` / `１：１` → `01:01`
- `15時15分`

数字だけ1～2桁のTIMEは意味が曖昧なので推測しません。

### 半角正規化

アマチュア無線の機械的な入力欄では、全角英数字・対象記号を半角へ正規化します。

対象例:
- 自局・相手コールサイン
- BAND
- MODE / Sub Mode
- RST
- JCC/JCG
- コンテスト英名・対象年月・コンテストナンバー

例:
- `ＪＨ１ＨＳＴ／１` → `JH1HST/1`
- `ＦＴ８` → `FT8`
- `－０１` → `-01`

### 日本語・全角を保持する欄

以下は自由文または日本語利用を前提とするため、全角を強制変換しません。

- ログファイル付与文字
- HIS QTH
- MY QTH
- RMKS

コンテストナンバーは日本語そのものは保持し、混在する全角英数字だけを正規化します。
