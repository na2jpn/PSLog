# PSLog Ver1.04 PATCH 09 — Ver1.048

適用元: Ver1.047 / PATCH 08 適用済みソース。

## JCC/JCG

- 保存・編集・所在地サジェストの自動入力はコードのみを正規形とします。
- `JCC 100101` → `100101`、`JCG 12345A` → `12345A`。
- JCGは5桁本体に任意の補助アルファベットを保持します。補助記号なしも正常です。
- 旧形式の接頭辞付き値もAJA/アワード判定では引き続き読めます。

## タブ移動

- 標準・コンテストともタブをドラッグ＆ドロップで左右へ移動できます。
- 移動後の順序は既存のワークスペース保存へ反映されます。
- コンテストタブの色は移動してもタブと一緒に移動します。`_tab_color_index` は実行中だけの情報で、設定ファイルには保存しません。
