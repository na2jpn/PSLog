# PSLog Ver1.04 PATCH 08 — Ver1.047

## 目的

同じバージョン番号の修正版（FIX）を、手動でフォルダー全交換しなくてもPSLogの正式なバージョンアップ機能から修復・再インストールできるようにする。

## Updater判定

選択した正式Windows版ZIPは、バージョン番号と現在インストールされている管理対象ファイルのSHA-256を確認して次の4状態に分類する。

- 新しいバージョン: 通常バージョンアップ
- 同じバージョン・同じ内容: 「すでに同じ内容」と案内して終了
- 同じバージョン・内容が異なる: 修復・再インストールとして許可
- 古いバージョン: 従来どおり拒否（ダウングレード不可）

同一内容判定では利用者データ (`config/`, `logbook/`, `bak/`, `output/`) は比較対象にしない。`pslog.exe`, `_internal/`, `exec/`, `meta/`, `docs/` の配布管理対象だけを確認する。

## 同じバージョンを再インストールする場合

同じVerで内容が違うZIPを選ぶと、次の確認を出す。

> 現在と同じ PSLog Ver1.047 です。  
> 選択されたパッケージは、現在インストールされている内容と異なります。  
> 修復・再インストールとして同じバージョンを上書きしますか？

`再インストール` を選んだ後も、PATCH 07で導入した全体バックアップ必須、外部Updater、自己診断、ロールバック、一時更新ロック、10秒後自動起動はすべて通常更新と同じように通る。

## セッション保護

PSLogから外部 `PSLogUpdater.exe` へ `upgrade` / `reinstall` の更新モードを一時セッションJSONで渡す。Updater側でもPSLog終了後にZIPを再検証し、現在の実ファイルを再判定する。画面で修復を選んだ後にZIPやインストール内容が変わった場合は、そのまま上書きせず更新を中止する。

## Ver
