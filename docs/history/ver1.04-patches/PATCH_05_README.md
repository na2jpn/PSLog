# PSLog Ver1.04 PATCH 05 — Ver1.044

PATCH 04 + FIX1 適用済みの Ver1.043 ソースへ上書きする差分です。

## 1. バージョンアップ画面

「ヘルプ → PSLogをバージョンアップ」を選んでも、いきなりファイル選択を開かないようにしました。
最初に説明画面を表示し、次を案内します。

- 現在のPSLogバージョン
- 新しいWindows版ZIPを展開せず、そのまま指定すること
- 通常配布の `PSLog_xxx_Windows_....zip` を使用できること
- ログ、設定、バックアップ、出力ファイルを保持すること
- 更新開始前に安全バックアップを作成すること
- 古いバージョンへ戻す更新はできないこと

「更新ZIPを選択…」を押した場合だけファイル選択へ進みます。

## 2. Windows配布ZIPを一本化

Ver1.043をUpdater運用開始基準とし、Ver1.044以降は通常のWindows版ZIPをそのままアップデートにも使用します。
`build-windows.ps1` は `PSLog_1.044_Windows_<timestamp>.zip` の1種類だけを生成します。
`UpdateFrom_...` の橋渡しZIPは通常ビルドでは生成しません。

## 3. 標準タブ「交信入力」

グループ上部の余白と縦spacingを少し詰め、相手コールサイン周辺の間延びを軽減しました。

## 4. ログ検索・編集

- 「対象自局」を手入力から選択式へ変更。
- PSLogログファイル名から自局コール候補を抽出。
- `JH1HST/1`, `JH1HST/P`, `JH1HST/JD1` 等は候補上では `JH1HST` にまとめる。
- 現在の自局コールに対応するベースコールを初期選択。
- 「指定自局の /1・/P 等の運用も含める」を初期ON。
- 「対象ログ名」を「ログファイル名」へ変更。

## 5. 通常エクスポート

- 「自局コールで候補検索」の手入力を、自局コール選択式へ変更。
- 候補はベースコールだけを表示。
- 例: `JH1HST` を選択すると、`JH1HST`, `JH1HST/1`, `JH1HST/P` 等にまつわるログファイルを候補一覧へ表示。
- 自局コール選択を変えると候補ログを自動更新。

## Windows確認

```powershell
python -m unittest discover -v
.\build-windows.ps1
```

ビルド後、releaseには通常の `PSLog_1.044_Windows_*.zip` だけが新規生成されることを確認してください。
このZIPは新規展開にも、Ver1.043以降の「PSLogをバージョンアップ」にも使用します。
