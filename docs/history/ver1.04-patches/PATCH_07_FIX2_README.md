# PSLog Ver1.046 — PATCH 07 FIX2

## 修正内容

PATCH 07で追加したQSO詳細のダブルクリック処理を、独立した「ログ検索・編集」画面だけでなく、メイン画面内の `LogSearch` 一覧にも接続しました。

- 標準タブの `LogSearch` をダブルクリックすると「交信詳細」を表示します。
- コンテストタブの `LogSearch` も同じ詳細画面を使用します。
- 詳細画面から「編集…」へ進んでも、メイン画面の入力途中の内容は保持されます。
- 編集保存後はログを再読み込みし、メイン画面の `LogSearch` を更新します。

Ver表示は `1.046` のままです。
