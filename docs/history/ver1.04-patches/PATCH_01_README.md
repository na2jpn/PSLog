# PSLog Ver1.04 PATCH 01

基準: `PSLog_1.03_CANONICAL_SOURCE.zip`

このZIPは変更ファイルだけの差分です。Ver1.03正本ソースのルートへ上書きしてください。
Ver1.03途中のPATCHを再適用する必要はありません。

## 実装内容

1. ログ検索・編集の日付/時刻範囲
   - 開始側の省略桁は指定範囲の先頭として扱う。
   - 終了側の省略桁は指定範囲の末尾として扱う。
   - 例: `20260917` ～ `20260917` で9月17日一日を対象。
   - 例: 終了 `2026091715` は15:59までを対象。
   - PSLog原本は分精度だが、比較境界は内部で秒まで持ち、日末は23:59:59として扱う。

2. 設定 → バックアップ
   - 保持数を「バックアップ保持数（ログファイルごと）」へ明確化。
   - 単位「件」を表示。
   - 自動バックアップの動作説明を平易化。
   - 実行中のPSLogから開いた場合、自動バックアップ保存先PATH、現在件数、対象ログ数、最新バックアップ日時を表示。
   - 月替わり機能は自動保存ではなく案内であることを明記。
   - 保持数を減らした場合の適用タイミングを明記。

3. ヘルプ
   - 「TXT書式」を「PSLogフォーマットについて」へ変更。
   - PSLogがTXTを正式原本とすること、1交信1行、UTF-8、新規BOM付き/CRLF等の概要を先頭で説明。

4. アワード → 4 実績・履歴（任意）
   - 縦一列レイアウトを整理。
   - 「過去の取得実績を登録」「今回選択した交信を履歴に記録」を左右2列のグループボックスへ分離。
   - 「登録済み実績」を下段の独立グループへ整理。
   - 説明文を簡潔化し、入力欄の高さと余白を圧縮して縦方向のオーバーを軽減。
   - AJA用の追加取り込み項目の既存表示制御は維持。

5. Ver1.04開始
   - ランタイムVERSIONを1.04へ更新。
   - 設定/ヘルプ/ログ統合等の表示、およびWindows配布ZIP名を1.04へ更新。

## 検証

- Python構文チェック: 実施済み。
- 日付範囲の非GUI回帰テスト: 実施済み。日単位・時間単位の終了側末尾補完を追加確認。
- この実行環境にはPySide6が無いため、Qt GUIテストはここでは実行できません。Windows側で通常の full suite / `build-windows.ps1` を実行してください。
