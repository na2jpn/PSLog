## コンテスト概要

コンテスト選択後、段階1の下部にスクロール可能な `コンテスト概要` を表示します。

表示対象:

- 主催
- 開催日時
- 提出締切
- 対象バンド / 対象モード
- マルチバンド / オールバンド相当部門の有無
- 参加できる局（規約データ上の地域区分・個人/社団/特別局等）
- 送信出力
- 移動運用
- 10分間ルール等の時間制限
- ナンバー交換
- 特記事項

概要文字は通常UIより1段小さくしますが、薄い色にはしません。出力制限、時間制限、特記事項など注意度の高い項目は青字です。

規約データにない情報は推測せず、`構造化記載なし` 等として表示します。提出締切のみ、登録済み提出案内文に明記された日付を保守的に抽出します。
