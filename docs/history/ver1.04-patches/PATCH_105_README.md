# PSLog Ver1.05 移行パッチ

基準: PSLog Ver1.049 / PATCH 10 + PATCH 09 FIX1 適用済みソース。

## このパッチの目的

- 製品バージョンを `1.05` へ移行する。
- Windows配布ZIP名を `PSLog_1.05_Windows_<timestamp>.zip` へ切り替える。
- ヘルプ、利用案内、配布チェック、回帰テストの現行バージョン表示を1.05へ揃える。
- 「最近閉じたタブ」から復活したとき、そのタブ自身の自局コールサインを確実に保持する。

## 最近閉じたタブの自局コール保持

閉じる時点のタブ状態を `recent_snapshot()` で明示的に保存し、再開時は `reopen_snapshot()` を通す。

- タブ固有の自局コールが保存されていれば、その値を必ず優先する。
- 古い設定や不完全な履歴で `call` が空の場合だけ、現在設定されている主自局コールを安全なフォールバックとして使用する。
- 標準タブ/コンテストタブの既存セッション形式は変更しない。
- ログファイルそのものには影響しない。

## 次チャット

Ver1.05のWindows実機確認後に全ソース正本ZIPを作成し、次チャットはその正本から開始する。
