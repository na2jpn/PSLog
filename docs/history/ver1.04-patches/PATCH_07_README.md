# PSLog Ver1.04 PATCH 07 — Ver1.046

PATCH 06 + FIX1 適用済みの Ver1.045 ソースへ上書きする差分です。

## 1. バージョンアップの安全性・案内

- 更新ZIPを確認した後、更新開始前に「今すぐバックアップ」で全体バックアップを必須化しました。
- 保存先をキャンセルした場合やバックアップ作成に失敗した場合は、更新を開始しません。
- 利用者向けの正式な復旧手順を「正常な新しいPSLogを用意 → PSLogの『バックアップ → 全体バックアップから復元』を実行」に統一しました。
- `.PSLogUpdateRollback-*` はプログラム差し替え中だけ使う内部一時領域です。正常更新・正常ロールバックでは削除します。
- 前回の異常終了で残った不要なRollback残骸は、PSLogが正常起動した時に整理します。ただし自動ロールバック自体に失敗して保全マーカーがあるフォルダーは自動削除しません。

## 2. Updater完了画面と更新待ちロック

- 更新成功後、新PSLogを先に起動せずUpdaterの完了画面を先に表示します。
- OKで今すぐ起動、操作しなくても約10秒後に自動起動します。
- 更新処理中は `bak/.pslog-update-active.json` を一時ロックとして使用します。
- 更新完了待ち中に `pslog.exe` を手動起動すると、次の案内を表示します。

  `PSLogのバージョンアップ処理が完了待ちです。`
  `更新画面から起動するか、約10秒そのままお待ちください。`

- 正式な新PSLogが起動すると、この待機画面も自動で閉じます。
- Updaterが異常終了した古いロックは次回起動時に無効化し、永久に起動不能にならないようにしています。

## 3. HIS QTH所在地サジェスト

- 標準タブのHIS QTHに所在地DBを使ったインライン候補を追加しました。
- 日本語・英語のどちらで検索しても候補を表示します。
- 日本語入力では日本語所在地、英字入力ではローマ字所在地を優先してHIS QTHへ反映します。
- 候補表示には日本語／英語／JCC・JCGを併記します。
- 候補選択、または所在地DBに一意の完全一致をした場合はJCC/JCGを自動入力します。
- HIS QTHの自由入力は維持します。
- JCC/JCGを利用者が手修正した後は、所在地補助がその値を勝手に上書きしません。

## 4. ログ検索のQSO詳細画面

- 「編集 → ログ検索・編集」で一覧行をダブルクリックすると、編集画面へ直行せずQSO詳細画面を開きます。
- 詳細画面では自局、元ログ、原本行、DATE/TIME、BAND、MODE/Sub Mode、相手コール、RST、HIS/MY QTH、JCC/JCG、RMKS、QSL判定・関連記録、原本行内容を確認できます。
- 詳細画面下部の「編集…」から独立した編集画面を開きます。
- 編集保存後は詳細画面へ戻り、保存後のQSOを再読込して表示更新します。
- 詳細・編集はモーダルで同時に複数開きません。
- メイン画面の標準/コンテスト入力途中データは一切流用・破棄せず保持します。
- 詳細画面には「メイン画面へ入力する場合は、このウィンドウを閉じてください。」、編集画面には保存またはキャンセルして閉じる案内を表示します。
