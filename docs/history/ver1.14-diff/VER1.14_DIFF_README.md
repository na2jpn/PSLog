# PSLog Ver1.14 差分

基準: `PSLog_1.13_CANONICAL_SOURCE.zip`

このZIPは Ver1.13 正本を展開したフォルダーへ上書きする差分です。
この時点では Ver1.14 正本そのものではありません。Windows側確認後に正本化してください。

## 変更内容

- `VERSION` を `1.14` へ更新。
- 初回起動ダイアログを刷新。初期表示は「アマチュア無線のコールサイン」。
- その直下のボタンで「フリラのコールサイン」へ切替可能。逆方向にも戻せます。
- フリラ開始時は同じ初回画面で「種類」「機種名（任意）」「ログ年（自動）」を設定します。
- フリラを選んだ場合、初回の空の標準タブをフリラタブへ置き換え、アマチュア無線のコールサイン未設定のままフリラだけで開始できます。
- フリラコールのカタカナ→平仮名変換、漢字等の拒否は既存ルールを使用します。
- 機種名空欄のフリラタブも再起動後に正しくSETされるよう修正。
- フリラタブから標準/EASY/コンテストを追加するとき、フリラコールをアマチュア無線コール欄へ引き継がないよう修正。
- フリラだけで使用している場合、`conf.cfg` のアマチュア無線用 `own` にフリラコールを書き込まないよう分離。
- 操作案内を1.14初回起動仕様へ更新。
- 現行VERSIONを固定値で確認する既存テストを1.14へ更新し、初回起動仕様の非GUI回帰テストを追加。

## Windows側で見るところ

1. 新規データ状態で起動し、初回画面が「アマチュア無線のコールサイン」で出る。
2. ボタンでフリラへ切替・戻しができる。
3. フリラでコール、種類、機種名空欄のまま開始できる。
4. 開始後、空の標準タブではなくフリラタブが選択され、交信入力できる。
5. 終了→再起動して、機種名空欄でも同じフリラタブが正常に復元される。
6. フリラタブから標準タブを追加したとき、フリラコールがアマチュア無線コール欄へ入らない。
7. 全テスト後、Windowsビルド名が `PSLog_1.14_Windows_...zip` になる。
