## 修正内容

### 仮想COMを「常設ケーブル」方式へ変更

com0comの仮想COMは、PSLogの起動・終了ごとに作成／削除しない方式へ変更しました。

- 無線機設定に **「仮想COMを作成」** と **「仮想COMを削除」** を追加しました。
- 作成・削除を実行したときだけWindowsの管理者権限（UAC）を要求します。
- 作成した仮想COMペアはWindows上に常設します。
- PSLog終了時や通常の「切断」では仮想COMデバイスを削除せず、中継用のCOMハンドルだけを閉じます。
- 次回PSLog起動時は、保存済みの仮想COMペアを再利用します。
- 通常の無線機接続ではUACを要求しません。
- 仮想COMを有効にしているのにペアが未作成の場合でも、物理無線機との接続は維持し、仮想COM側だけ案内を表示します。

### 仮想COM作成の流れ

1. com0comをインストールし、`setupc.exe` を指定または自動検出させます。
2. 無線機の実COMを指定するか、一度接続して物理COMを確定します。
3. 「仮想COMを作成」を押します。
4. WindowsのUAC確認に許可します。
5. 例として物理COM8の場合、空いていれば外部ソフト用にCOM208を作成します。競合時はCOM308、COM408…と+100します。
6. 「仮想COM中継を使用する」をONにしてPSLogを接続します。
7. WSJT-X等の外部ソフトでは、PSLogに表示されたCOM208等を選択します。

仮想COMを削除する場合は、先にPSLogの無線機接続を「切断」してから「仮想COMを削除」を実行します。

### 周波数表示

メイン画面右上の周波数表示を、従来より **2pt大きく、ボールド** にしました。
接続時の緑、未接続時の薄いグレーという表示色は従来どおりです。

## Windowsで確認してほしい項目

1. 「仮想COMを作成」でUACが1回表示され、COM208等が作成されること。
2. 作成後、PSLogを終了しても仮想COMがWindows上に残ること。
3. PSLogを再起動し、UACなしで仮想COM中継を開始できること。
4. 「切断」で無線機と中継は停止するが、仮想COMデバイス自体は残ること。
5. 「仮想COMを削除」でUACが表示され、PSLog管理の仮想COMが削除されること。
6. WSJT-X等から外部用COMを開き、PSLog経由でCI-V通信できること。
7. 周波数表示が2pt大きくボールドになっていること。
