## 検証

新規10テストを含む関連248テスト成功。全72種目のR1.0をJSTとUTCで出力確認。
同じ局とのCW・電話・RTTYは独立した提出。電話内SSB/AM/FMの重複は1回。
QRPは5W以下、5.001Wは停止。RTTY部門にFT8/FT4を含めない。
提出用の絞り込みは本大会で明示指定した機能。FDなど他大会の履歴保持を一律変更しない。
部門内の無得点交信は残す。元の選択一覧・原PSLog TXT・元の備考は変更しない。
ニューカマーはSOの個人/社団局が希望時に申告。初開局2023-09-20～2026-09-20、再開局は対象外。申告不備は採点値を変更せず提出時に停止。
