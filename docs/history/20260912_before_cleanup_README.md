## この版で実装したこと

- PSログTXTのUTF-8 BOMあり・なし、LF・CRLF読み込み。
- 11項目と旧10項目行の読み取り、見出し・空行・年区切りの分類。
- 問題行の行番号・理由付き報告。問題行があるファイルへの更新停止。
- 自局とDATEに基づく年別ファイル名、スラッシュのハイフン化。
- 新規ファイルはBOM付きUTF-8・CRLF・末尾バックスラッシュ2文字。
- 既存の非編集行は元バイトを保持。BOM・既存改行も保持。
- スナップショットによる外部変更検知。一時書き込み・fsync・置換。
- 最初の書込前、編集削除・復元前、変更したログの終了時バックアップ。
- 同一内容のバックアップ抑制、ログごと初期30世代（10・30・60・100から選択）。
- 編集・削除・復元の保存API。復元直前の原本も保護。
- メイン画面の記録を実TXT保存へ接続。自局完全一致のLogSearch。
- 直近自局・MY QTH・入力補助チェックをconfig/conf.cfgへ保存。
- 初回自局入力、絶対パス表示、画面全体のスクロール。
- FT8/FT4/FT2=-01、FreeDV=+00、RTTY=599、サブモード補助。
- DATE/TIME全角正規化、日時の入力チェック。
- メイン画面の位置・サイズ・最大化状態を保存し、現在のモニター作業領域に補正して復元。
- 極小・画面外・モニター取り外し時に補正。小さい画面では実作業領域以内に収めてスクロール。
- カスタムダイアログにも外側スクロールと表示位置補正を追加。
- 設定画面：記録確認ON/OFF、RST補助・BAND/MODE維持、保持世代数、月替わり案内。
- 全ログ・設定のZIPバックアップ。月替わりの起動時に案内し、同月は再表示しない。
- 設定保存は既存の追加項目を保持し、外部変更があれば上書きを停止。
- ブラックリスト管理：登録・検索・編集・確認付き削除。完全一致が既定、登録ごとに移動運用包含を選択。
- メインのコールセット時と直接記録時に警告。OK後も記録可能、RMKS不変。
- HAMLOG CSVインポート（15/16列の暫定対応）、CP932／UTF-8、J/Uと2桁年指定、OP・RemarksをRMKSへ保持。HAMLOG_IMPORT_MAPPING.md参照。
- ADI／ADIF／ADXインポート、UTC→JST、秒と追加項目のRMKS保持、自局不一致確認。詳細はADIF_IMPORT_MAPPING.md。
- 通常エクスポート：自局候補検索、チェック選択、秒単位JST期間、最新N件、出力前確認。
- ADI／ADXのUTC変換・独自項目保持。同名は連番保存。原本は変更しない。
- HAMLOG CSVは互換性確認用の暫定版。詳細と制限はEXPORT_MAPPING.mdを参照。
- PSログTXTインポート画面：DATEの年で振り分け、重複除外（既定）／全追加、年別件数の事前確認。
- 要確認行の除外は明示選択。運用区切りは指定自局への一律取り込みを確認。
- 既存の全保存先を事前バックアップし、ファイルごとに安全に置換。結果JSONをbakへ保存。
- バックアップ復元画面：ログ名で絞り込み、復元元／先の絶対パスと交信件数を確認。
- 確認後の原本・バックアップの変更を検知して復元を停止。削除済み／UTF-8読取不能な原本にも復元可能。
- 復元前の原本を保護し、そのバックアップから戻せる。復元確認は「いいえ」が既定。
- 専用検索画面：自局、運用サフィックス、ログ名、相手コール、RMKS、JST日時範囲、BAND、MODEで絞り込み。
- 検索結果の件数上限なし。表の内部スクロールと右側詳細表示。
- 選択交信の11項目編集、変更差分表示、入力検証、保存後の再検索。
- 削除確認画面はキャンセルが既定。原本行とスナップショットで対象を保持。
- 編集時のMODE変更でRSTを自動変更しない。現在のMY QTHも維持。
- 実ログを原本変更なしで調べるaudit.pyと、年別取り込みの仮計画。

## 開発者向けの起動

必要な環境を確認してから不足分だけ準備してください。アプリはソース起動時にはmain.pyの所在、EXEではEXEの所在をデータルートにします。

```text
python main.py
python -m unittest -v test_storage
python -m unittest discover -v
python audit.py input.txt --call JH1HST --root data --report audit-result.json
```

audit.pyは読み取り専用です。指定するreportは未使用のファイル名にしてください。
入力に/JD1等の運用区切りがあっても指定自局を自動変更しません。年別件数は自局を一律に仮定した計画にすぎません。

build-windows.ps1は開発者用のビルド手順です。既存環境の確認とWindows上の試験を終えてから使用します。実行済みのEXEではありません。
