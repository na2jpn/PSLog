# PSLog 1.19 FIX7

## 実装

location_optionsを追加し、完全一致したコールのAPIレコードを所在地文字列ごとに集約する。住所文字列のNFKCと前後空白除去後の一致だけでまとめ、市区町村コードが同じだけの異なる住所はまとめない。
一覧listInfo/詳細detailInfoのlicenseDateとvalidTermsを表示する。実装が現在要求しているDA=0の応答に満了日がなければ未取得とする。日付を埋めるための追加API呼出しは行わない。年号（令和・平成・昭和、元年含む）と西暦の日付を実在日チェックし、開始日を優先、全候補に開始日がなければ全候補の満了日で比較する。日付欠落・同日の場合は最新を断定しない。未知形式の文字列も表示は保持し、並べ替えの根拠にしない。
参照したフィールドの実装例（現在の公式仕様を取得したという意味ではない）：https://pkg.go.dev/github.com/tomato3713/soumuradio@v0.5.2/internal
複数所在地は同一QSOの候補行へ展開し、件数制限は元の交信数単位のまま。最終日時も元交信の日時。選択状態は候補に保持し、JCC/JCG補完ON/OFFの再表示後も維持する。GUIで他候補を無効化し、コアcommitでも同一QSOの複数選択を拒否する。通常の既存バックアップ・外部変更検知・復旧処理を利用する。
表は10列、初期幅は見出しを読める幅以上とし、手動Interactiveのまま「結果」列が画面の余白を利用する。自動内容幅調整を取り除いた。
