# PSLog 1.21

2026年10月22日

## バックアップの保存数を制限

- 通常ログのバックアップは、既存の「設定 → バックアップ → バックアップ保持数」を維持します。10・30・60・100件から選択でき、初期値は30件です。
- 完了済み一括処理・年変更の回復記録、ログ統合前の控え、アワード・所在地設定・コンテスト定義・Cabrilloテンプレートの変更履歴にも保持数を適用します。
- 全体復元前の安全バックアップZIPは直近2世代を保持します。
- 起動・終了時に既存の蓄積分を整理し、正常に完了した保存後も古いものを整理します。
- ログと変更履歴は元ファイルごと、完了済み回復記録は保存先の種類ごとに制限します。保持数はフォルダー全体の総ファイル数ではありません。
- 未完了の回復記録、復旧失敗として保護された記録、未確定の旧設定の退避、利用者が任意の場所へ保存した全体バックアップZIPは自動削除しません。リンク先やPSLogの命名規則に合わないファイルも対象外です。
- 削除できないファイルがあっても正常な保存を失敗扱いにせず、次回の整理時に再試行します。

## RBN接続先の変更

- C枠の初期候補を上海から `telnet.reversebeacon.net:7000` へ変更しました。CW・RTTY用の接続先で、クラスタ用の設定コマンドは送信しません。
- 以前の標準上海設定は新候補へ移行します。有効・無効の選択と、利用者が独自に変更した接続先は保持します。
- A〜Eの巡回間隔、国内クラスタの取得間隔、スポットの表示保持時間は従来どおりです。

本ZIPは1.20正本までの変更をすべて含むフルソースです。旧差分の追加適用は不要です。
Windows EXEビルドと実回線RBN受信は、この環境では未確認です。

## バックアップ設定

設定 → バックアップの保持数 N（初期30、10/30/60/100）を使います。

| 対象 | 上限 |
|---|---|
| bak直下の通常ログ控え | 元ログごとにN |
| bak/batch_recovery の完了済み記録 | N |
| bak/year_moves、year_moves_flr の完了済み記録 | 保存先ごとにN |
| bak/logbook_bak | 元ログごとにN |
| bak直下のインポート結果記録 | N |
| config/awards の変更控え | 台帳ごとにN |
| config/db/history の所在地確認設定控え | N |
| ルール・Cabrilloのhistory（bundled、pack含む） | 元ファイルごとにN |
| bak/full-restore-safety、update-safety | 保存先ごとに2 |

起動・終了時に既存分を整理し、関連する正常な保存後にも整理します。新しい状態の保存が失敗した処理では、保存後整理を実行しません。元ログ・現用設定・申請履歴本体は削除しません。
未完了記録が残る場合、関連するログ控え・完了済み記録の整理も見送ります。解決するまで上限を超えることがあります。
失敗した全体復元の安全ZIPには `.keep` 保護印を付け、通常の2世代とは別に保持します。これらの保護分や、更新ロールバックの失敗記録は自動削除しません。未確定の旧設定（config/restored_legacy）も保持します。
任意の場所へ手動保存した全体バックアップZIPは整理対象外です。必要な長期保存用ZIPは従来どおり手動で作成できます。
他ソフトのデータやリンク先は対象外です。削除に失敗した場合は起動時の状態表示・終了時の案内や診断ログに残し、次回に再試行します。

## ターゲットアラート

コール例：`JX1XXX, JX2XXX`。JCC/JCG例：`1318, 13001, 13001A`。
各欄のSETを押すと、その欄だけ保存・適用します。入力したカンマ区切りの文字列を保持します。SET前の編集は開始・終了時にも適用しません。空欄でSETするとその欄の条件を解除します。先頭・末尾のカンマ、連続カンマ、空白は無視し、全角英数字・全角カンマも受け付けます。不正な要素はダイアログで知らせ、直前の保存済み条件を保持します。

コール条件と地域条件はOR一致です。移動表記のないコールは移動局表記も対象。JCGの郡番号のみは郡全体、末尾アルファベット付きは町村単位です。RBNではコール条件だけ照合し、JCC/JCGは推測しません。

監視開始時に既にある国内情報は表示だけ、新着一致は1件につき通知音1回。音のON/OFFは画面上部、音量・音種は設定→通知音で変更できます。画面を閉じると通知と受信を停止します。再表示時には自動開始しません。国内一覧は最大2000行です。

## バンドサイト

下段に○-FTを追加。通常バンドはFT8/FT4を除く周波数軸、○-FTはFT8/FT4専用の周波数別カードです。通常とFTを合わせて最大8枠。「すべて／JA局のみ／DX局のみ」を両表示へ適用します。

1.8〜5600 MHzのバンドボタンで表示を選択／解除します。同時表示は最大8バンド。1つなら全体、2つなら左右、4つなら2×2、8つなら2×4に分割します。選択は保存されます。初期表示は7 MHzです。受信開始を押すまで通信しません。

縦軸はMHzです。周波数・MODE・コールサインを表示し、同じMHz内の整数部は省略（例：7.010 MHz→.010）します。近接した表示は位置をずらして線で実周波数に結びます。各バンドの領域は独立しており、隣のバンドへ描画しません。文字が収まらない場合は省略し、マウスを置くと周波数全桁、日時JST、情報源、報告局、地域、コメントを確認できます。混雑時は新しい情報を優先し、「他N局」に置くと追加情報（最大40件）を表示します。

直近30分の情報を対象とします。通常モードは同じ局・周波数（0.1kHz単位）・MODE、FTは同じ局・MHz小数点2桁の周波数・MODEで重複をまとめます。CW=青、SSB=緑、FM/AM=紫、FT8=橙、FT4=桃、RTTY=青緑、その他=灰。色とMODE文字を併記します。表示範囲は送信可能範囲を示すものではありません。スポット操作で無線機周波数を変更する機能は含みません。

## インターネットとRBN

国内クラスタはアプリ全体で最短5分間隔。失敗時は待機を延長します。停止・再開や画面を開き直しても短時間の再取得はしません。別画面が受信中なら、その接続は最後の画面が停止するまで継続します。閉じた画面には結果・音を届けません。停止時点で進行中のHTTP処理は終了待ちになります。

RBNは任意です。両ツールの「RBN設定」で共通のA〜E接続先とログインコールを保存します。有効枠を60秒ごとに巡回し、5枠有効なら約300秒で一周。情報を保持して重複表示・通知を抑止します。各接続先の再接続は5分以上空けます。C候補はtelnet.reversebeacon.net:7000（CW・RTTY）です。接続テストで確認してください。バックアップの保持方針はdocs/BACKUP_RETENTION_1.21.mdを参照。

## 起動・ビルド

ソース実行：`python main.py`。WindowsのEXE作成は `WINDOWS_BUILD.md` と `build-windows.ps1` に従ってください。依存関係は `requirements.txt` に記載しています。Windowsビルドではテストを通過してからPyInstallerを実行します。

既存ログ・設定は従来どおり利用します。ターゲット条件は従来の `config/cluster_monitor.json` を引き継ぎ、バンド表示設定は `config/band_site.json` に保存します。個人ログ、個人設定、生成済みEXEはこのZIPに含みません。既存の1.19のアワード管理、総務省照会、通知音、HIS QTHの開始日時・件数・待機・複数所在地処理を継承しています。

検証の詳細：`docs/VALIDATION_1.21.md`。Windows実機・EXEビルド・RBN実接続は別途確認が必要です。
