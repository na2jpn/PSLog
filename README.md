# PSLog 1.20 — 2026-10-20

1.19正本（FIX1〜FIX7統合）を基準にしたフルソースです。過去の差分ZIPを追加適用する必要はありません。

- ツール→**ターゲットアラート**：旧「クラスタ監視」を改称。コールサインとJCC/JCGを、それぞれカンマ区切りの入力欄とSETボタンで保存・適用します。
- ツール→**バンドサイト**：独立したウィンドウに最大8バンドの周波数軸とスポットを表示。MODEごとに色分けします。
- HIS QTH作成：ログへの反映に成功したら結果一覧を消去します。保存失敗時は結果を残します。

両ツールは同時に開けます。メイン画面の操作も継続できます。国内クラスタの取得と同一設定のRBN接続は2画面で共有し、画面数によって取得頻度を増やしません。

## ターゲットアラート

コール例：`JX1XXX, JX2XXX`。JCC/JCG例：`1318, 13001, 13001A`。
各欄のSETを押すと、その欄だけ保存・適用します。入力したカンマ区切りの文字列を保持します。SET前の編集は開始・終了時にも適用しません。空欄でSETするとその欄の条件を解除します。先頭・末尾のカンマ、連続カンマ、空白は無視し、全角英数字・全角カンマも受け付けます。不正な要素はダイアログで知らせ、直前の保存済み条件を保持します。

コール条件と地域条件はOR一致です。移動表記のないコールは移動局表記も対象。JCGの郡番号のみは郡全体、末尾アルファベット付きは町村単位です。RBNではコール条件だけ照合し、JCC/JCGは推測しません。

監視開始時に既にある国内情報は表示だけ、新着一致は1件につき通知音1回。音のON/OFFは画面上部、音量・音種は設定→通知音で変更できます。画面を閉じると通知と受信を停止します。再表示時には自動開始しません。国内一覧は最大2000行です。

## バンドサイト

FIX2では下段に○-FTを追加。通常バンドはFT8/FT4を除く周波数軸、○-FTはFT8/FT4専用の周波数別カードです。通常とFTを合わせて最大8枠。「すべて／JA局のみ／DX局のみ」を両表示へ適用します。

1.8〜5600 MHzのバンドボタンで表示を選択／解除します。同時表示は最大8バンド。1つなら全体、2つなら左右、4つなら2×2、8つなら2×4に分割します。選択は保存されます。初期表示は7 MHzです。受信開始を押すまで通信しません。

縦軸はMHzです。周波数・MODE・コールサインを表示し、同じMHz内の整数部は省略（例：7.010 MHz→.010）します。近接した表示は位置をずらして線で実周波数に結びます。各バンドの領域は独立しており、隣のバンドへ描画しません。文字が収まらない場合は省略し、マウスを置くと周波数全桁、日時JST、情報源、報告局、地域、コメントを確認できます。混雑時は新しい情報を優先し、「他N局」に置くと追加情報（最大40件）を表示します。

直近30分の情報を対象とし、同じ局・周波数（0.1kHz単位）・MODEの重複をまとめます。CW=青、SSB=緑、FM/AM=紫、FT8=橙、FT4=桃、RTTY=青緑、その他=灰。色とMODE文字を併記します。表示範囲は送信可能範囲を示すものではありません。スポット操作で無線機周波数を変更する機能は含みません。

## インターネットとRBN

国内クラスタはアプリ全体で最短5分間隔。失敗時は待機を延長します。停止・再開や画面を開き直しても短時間の再取得はしません。別画面が受信中なら、その接続は最後の画面が停止するまで継続します。閉じた画面には結果・音を届けません。停止時点で進行中のHTTP処理は終了待ちになります。

RBNは任意です。両ツールの「RBN設定」で共通のA〜E接続先とログインコールを保存します。有効枠を60秒ごとに巡回し、5枠有効なら約300秒で一周。情報を保持して重複表示・通知を抑止します。各接続先の再接続は5分以上空けます。C候補は中国・上海BH4HKZへ変更しました。接続テストで確認してください。設定・制限の詳細はFIX2_README.mdを参照。

## 起動・ビルド

ソース実行：`python main.py`。WindowsのEXE作成は `WINDOWS_BUILD.md` と `build-windows.ps1` に従ってください。依存関係は `requirements.txt` に記載しています。Windowsビルドではテストを通過してからPyInstallerを実行します。

既存ログ・設定は従来どおり利用します。ターゲット条件は従来の `config/cluster_monitor.json` を引き継ぎ、バンド表示設定は `config/band_site.json` に保存します。個人ログ、個人設定、生成済みEXEはこのZIPに含みません。既存の1.19のアワード管理、総務省照会、通知音、HIS QTHの開始日時・件数・待機・複数所在地処理を継承しています。

検証の詳細：`docs/VALIDATION_1.20_FIX2.md`。Windows実機・EXEビルド・RBN実接続は別途確認が必要です。
