PSLog 1.14 Windows配布確認票

[配布構成]
[ ] ルート直下の通常ファイルは pslog.exe のみ。
[ ] exec\PSLogUpdater.exe が存在する。
[ ] meta\BUILD_INFO.json と meta\PSLOG_UPDATE_INFO.json が存在する。
[ ] config / logbook / logbook_flr / bak / output の利用者データを配布ZIPに含めていない。

[起動]
[ ] PSLog Ver1.14 と表示される。
[ ] 初回既定サイズは1360×850基準で、狭い画面では画面内に収まる。
[ ] `pslog.exe --reset-window` が機能する。
[ ] logbook / logbook_flr が不足時に生成される。

[Ver1.14重点]
[ ] JCC/JCG交信チェックの集計中Loadingが動き、UIが固まらない。
[ ] 都道府県折りたたみとCFM残JCC/残JCGが正しく表示される。
[ ] QSL処理専用画面と QRZ.R / CARD.R が機能する。
[ ] EASYタブは最大2枚で、[E]CALL と表示される。
[ ] EASY 1/2ページと2/2ページを往復できる。
[ ] EASY 2/2ページのJCC/JCG→名称、His/My QTH、RMKS、JST時刻が機能する。
[ ] 入力時刻と現時刻が5分以上違う場合、キャンセル/現時刻/入力時刻の選択が出る。
[ ] EASY登録後はBand/Mode/Sub/My QTHを保持し、相手側情報をクリアする。
[ ] EASYのバンド表記が「バンド（MHz）」、外枠が緑。
[ ] フリラタブは同時最大4枚、選択色は水色。
[ ] 初回起動でアマチュア無線/フリラのコールサイン入力を切替できる。
[ ] フリラを選び、機種名空欄でもアマチュアコール未設定のまま開始できる。
[ ] フリラのみで開始後に再起動して同じフリラタブが復元される。
[ ] フリラタブから標準/EASY/コンテストを追加しても、フリラコールがアマチュアコールとして引き継がれない。
[ ] ＋タブからフリラを新規作成でき、同一ログブックは重複タブにならない。
[ ] 不正コール警告後もフリラタブ追加ダイアログが残り、機種名空欄でも作成できる。
[ ] カタカナのフリラコールが平仮名へ変換され、漢字は拒否される。
[ ] 種類に応じてBAND/MODEが自動設定される。
[ ] フリラ右側LogSearchが同じ自局コールの全種類を横断し、種類列を表示する。
[ ] メニュー「フリラ」の既存タブ呼び出しとフリラログ検索・編集が機能する。
[ ] 別系統タブから検索を開いた時は対象自局が「選択してください」となり、未選択では検索できない。
[ ] 全体バックアップ/復元にlogbook_flrが含まれる。

[既存機能]
[ ] 標準タブは [A]CALL 表示、選択中は薄緑背景。
[ ] コンテスト管理一覧に開催年月が表示される。
[ ] 愛・地球博の提出時刻はJST、バンド順オプションは初期ON。
[ ] QSL一括TXTの3/4項目・順序自由が動き、時刻はコロン形式を使用する。
[ ] RMKS2が11項目を増やさずRMKS内予約区切りで保持される。
[ ] 通常エクスポート、POTA/SOTA、コンテスト/QSOパーティ/アワードが動く。

[Updater]
[ ] 通常の PSLog_1.14_Windows_*.zip を新規配布/アップデートの両方に使える。
[ ] 更新前全体バックアップが必須。
[ ] config / logbook / logbook_flr / bak / output を保持する。
[ ] 更新後の自己診断、完了画面、自動起動、更新ロック解除が正常。
